# 判决术语权威表 v1

> **为什么需要这张表**：第二轮 13 家报告里，「不买」这个词被不同 Agent 用出了至少两种相反的意思，而「观察等待」与「不买」在 8 份大师之间被随机互换。用户在读到「芒格不买，35/31/27」时无法判断到底买不买。本表把**判决**拆成两个正交维度，任何报告必须同时给出这两个维度。

---

## 一、两个正交维度

| 维度 | 取值 | 说明 |
|---|---|---|
| **维度 A：现价动作** | 做 / 不做 | 以报告写定时点的收盘价为准，这一笔建不建仓 |
| **维度 B：是否有可执行买入价** | 有 / 无 | 是否存在一个「到这个价、加上这些条件，我就买」的可执行方案 |

**两个维度必须分别报，不允许用一个词同时表达。**

---

## 二、四个标准判决词（唯一合法取值）

| 编号 | 标准词 | 现价动作 | 可执行买点 | 定义（判据） |
|---|---|---|---|---|
| **V1** | **买入** | 做 | 有 | 现价已可建仓。允许分批（首档即现价或低于现价 ≤3%），仍记为 V1 并在仓位列注明「分批」 |
| **V2** | **观察等待** | 不做 | **有（常规档）** | 现价不做；存在 X 价 + **常规经营条件**（如毛利率止跌、CFO 达标、分红维持）即可买入 |
| **V3** | **现价不买** | 不做 | **有（苛刻档）** | 现价不做；存在 X 价，但触发条件**明显更严**——例如「价格须低于清算价值」「checklist 全绿」「须等到某一期财报的四项数据」「须先看到分拆条款」 |
| **V4** | **否决** | 不做 | **无** | 现价不做，**且没有任何价格能触发**。判据必须落在**生意模式或能力圈**上（"这个生意我看不懂 / 我不投这类生意 / 它有期限且无续期"），**不能**落在价格上 |

### V2 与 V3 的唯一区别

**不是价格高低，是"还差什么"的性质**：
- V2：主要差价格，条件是用来确认「便宜不是陷阱」
- V3：差的是**关键信息或关键前提**（土地/特许权年限、分拆条款、清算值真实性、某期经营数据），价格只是必要条件之一

**两者都"给买点"，都"现价不做"。** 所以"不买 + 给买点"在 V2/V3 里是正常的、不矛盾的。

### V4 的严格门槛

**只有在写出「为什么任何价格都不投」时才能用 V4。** 常见合法理由：
- 生意模式本身不过关（如「每一元新增资本只赚回 7%，低于资本成本，且我看不到改变」）
- 能力圈外（如「8 个分部我只看得懂 1 个」）
- 资产有硬性到期且无续期（如「特许权到期无偿移交且不可续期」）

**不合法的 V4 理由**：任何以"太贵""PE 太高""分位太高"为唯一理由的，一律是 V2 或 V3。

## 三、必须同时报告的五个字段

任何一份报告的判决章节，必须给全这五项，缺一不可：

| 字段 | 格式 | 例 |
|---|---|---|
| 1. 判决分布 | `V1 买 n / V2 观察 n / V3 现价不买 n / V4 否决 n` | `0 买 / 7 观察 / 1 现价不买 / 0 否决` |
| 2. 首档中位 | 具体价格（元） | `35.00` |
| 3. 核验官买点 | `T1 x / T2 y / T3 z`（须与 `audit.md` 逐字一致，附行号） | `28 / 24 / 20`（audit.md L24） |
| 4. 现价 vs 核验官中枢 | 折价或溢价 % | `现价比中枢 28.1 高 85%` |
| 5. 每位 V3/V4 的「那什么价、什么条件、多少仓位会让你买」 | 逐人一句，带原文引证 | 见各报告 §0.1 |

## 四、旧标签 → 新标签 映射规则

第二轮报告在 2026-11-26 之前使用的旧标签，按下表重写：

| 旧标签 | 可能对应 | 判定方法 |
|---|---|---|
| 「买入」/「分批买入」 | **V1** | 首档 ≤ 现价 ×1.03 → V1 |
| 「观察等待」 | **V2**，若触发条件含"须先拿到某关键信息"则升为 **V3** | 读其 buy_points 的 trigger 字段 |
| 「不买」 | **V3**（若给了买点）或 **V4**（若未给买点且理由是生意模式） | **看有没有 buy_points / 看理由落在价格还是生意** |
| 「推翻为不买」 | 多数为 **V4**，少数为 **V3** | 同上，逐案判断 |

**判定禁令**：不得按字面翻译。旧标签的每个实例都必须回到其 `.md` 原文，看「有没有给可执行买点」与「理由落在价格还是生意」，再落到 V1–V4。
