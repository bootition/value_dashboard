# 首次使用与日常操作指南（用户手册）

> G1（`reports/42` §2）：面向「接受本地部署与 CLI」的个人用户，
> 从用户目标出发的操作路径说明。目标：一名不参与开发的用户，
> 借助本手册在 10 分钟内完成「启动 → 确认数据日期 → 新建并运行规则 →
> 保存 → 导出」，遇到 `warning`/`_truncated` 时知道下一步。

## 1. 启动与停止

**入口：** 双击项目目录中的 `start.bat`（或发行目录中的 `value-dashboard.exe`）。

- 启动后会自动打开浏览器 `http://127.0.0.1:8765`，进入「筛选」页。
- **浏览器打不开？** 手动在浏览器地址栏输入 `http://127.0.0.1:8765`。
- 停止：关闭启动窗口（黑窗口）即停止服务。数据已持久化，重启不丢失。

## 2. 先看数据状态

顶部菜单进入「**数据状态**」页：

- **数据是否可研究？** 看「数据质量」就绪状态与 `warning_codes` 列表（为空 = 全部正常）。
- **价格/财报分别截至哪天？** 看页面上各数据集的 `latest` 日期；「数据新鲜度」卡片也会在个股页显示价格日期。
- **更新中能否使用？** 更新进行中（`STALE_RUNNING_JOBS` 等警告）时，保存/导出会被暂时禁用，等待完成即可。
- CLI 查看：`vd data auto-update status`。

## 3. 第一次筛选

> 可以直接运行；系统会自动把当前草稿保存为一个可追溯的规则版本。也可以先手动输入规则名称并点击「保存新版本」。

1. 「基础股票池」：选择是否排除 ST / 停牌、最低上市年限。
2. 「数据质量」：可开启「仅查看 strict」（只用严格置信度字段的股票）。
3. 「筛选条件」：添加条件，例如 `pe_ttm < 15`（PE-TTM 小于 15）。
4. 「排序」：设置优先级（如 `pe_ttm` 升序）。
5. 点击「**运行筛选**」，系统会自动保存草稿规则并运行，结果出现在下方表格。

**规则已保存过？** 直接在「加载规则」下拉选择规则版本即可运行。

## 4. 可信度与截断

- **strict / approximate / null**：字段来自不同数据源时置信度不同；「仅查看 strict」只保留全部使用字段为 strict 的股票。`null` = 该股票此字段无数据，不是 0。
- **`_truncated`（结果已截断）**：匹配数超过 5000 条时，只展示前 5000 条，页面顶部出现「结果已截断」警告；此时保存的结果与导出的 CSV 同样只含这 5000 条，CSV 表头带 `_truncated` 列（值为 True）。**缩小筛选条件**即可看到全部匹配。
- **何时不要保存/导出？** 页面出现「数据质量警告」且受影响字段包含你的筛选/展示字段时，保存和导出按钮会被禁用——这是保护措施，先前往「数据状态」页处理。

## 5. 保存、导出、自选

先后关系：**运行 → 保存 →（导出 / 加入自选）**。

1. 运行筛选后点击「**保存结果**」，填写标题（备注可选）。
2. 「**导出 CSV**」：基于已保存的结果导出，文件含数据日期、规则版本、指标版本、置信度、字段溯源与 `_truncated` 标记。
3. 「**加入自选**」：把当前结果全部加入自选（分组 `screening`），之后在「自选列表」页查看。
4. 自选页可手动添加 6 位股票代码（如 `600519`），移除时需确认。

## 6. 个股研究

从筛选结果或自选列表点击股票代码进入个股详情页：

- **价格**：K 线图可选不复权 / 前复权；右上角显示最新收盘价与价格日期。
- **财报口径**：指标页可在 年度 / 季度（单季）/ TTM 间切换；季度为单季值（非累计）。
- **业务概览**：公司简介、经营范围、行业与主营构成（按产品/行业/地区），显示报告期与来源置信度。
- **历史股本与研究统计**：PE/PB/TTM股息率/利差的 1/3/5/10 年及全部历史窗口的经验分位带与 μ±σ 带；口径为「最新重述回看」（不代表当时市场可见信息，不用于回测）。
- **国债比较**：TTM 已实施股息率（过去 12 个月已除权且已公告现金分红 / 收盘价）相对所选期限国债收益率的利差历史；期限可选 3月/6月/1/2/3/5/7/10/30 年；曲线取不晚于价格日的最近发布点，最大陈旧 5 个自然日（陈旧或缺失时利差为空并注明原因）。
- **溯源**：底部「溯源信息」列出每个字段的数据来源与置信度。
- **数据日期**：留意页面上每个卡片的数据日期，历史财务（2026-03-31 之前）为 CSMAR 商业导入值。

## 7. 日常维护

- 自动更新在启动时后台运行；「数据状态」页可查看进度与重试列表。
- 新数据域（国债曲线、历史股本链、历史研究统计）由自动更新按各自节流策略维护；
  「数据状态」页的 retry/missing 列表可用 `?data_type=` / `?field_prefix=` 过滤查看。
- CLI 常用命令（在项目根目录执行）：

```bash
vd data auto-update status   # 查看更新状态
vd data update --help        # 手动触发/暂停等
vd status                    # 数据库就绪状态
vd data treasury-curve --check-only   # 国债曲线覆盖与队列状态
vd data capital-history --check-only  # 历史股本链覆盖状态
```

## 8. 备份与恢复

- **何时备份？** 重要研究结果/自选产生后，或执行任何写操作前。
- 备份：`vd backup create`（详见 `vd backup create --help`；备份文件保存在独立目录）。
- **恢复风险：** 恢复会用备份文件**覆盖当前数据库**（股票列表、自选、结果、草稿）。恢复前先创建新备份，按备份命令的输出提示操作。

## 9. 已知边界（诚实披露）

| 项 | 说明 |
|---|---|
| 免费源缺口 | 极新股 `920305` 等免费源无数据，价格/股本/分红如实显示缺失 |
| 银行/券商监管字段 | 资本充足率、不良贷款率等 92 只无免费结构化数据，保持 NULL（不是 0） |
| 东财源 | 部分时段不可用；系统自动回退腾讯/Sina/BaoStock，网络恢复后自动可用 |
| 非投资建议 | 本工具仅用于个人本地研究，不构成投资建议 |

**遇到问题：** 页面错误提示均给出中文原因与下一步；仍无法解决时查看
`docs/STATUS.md` 的已知缺口清单，或运行 `vd --help` 查看 CLI 能力。
