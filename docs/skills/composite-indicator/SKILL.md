# 复合指标构建（A股 · 本仓库）

> 这个 Skill 的来源是 `reports/131 §10` 的 8 个真实坑：ROCE 在 40 小时内返工四次
> （`reports/128 → 129 → 130 → 132`），每一版都能算出错误的数字，而且**不报错**。
> 本 Skill 把那 8 个坑反推成 10 个必须按顺序执行的步骤。

## 什么时候用

- 新增一个比率类 / 复合指标，或修改已有指标的口径；
- 给指标加筛选条件、筛选标志（如 `roce_eligible`）；
- 加"历史中位数 / 趋势 / 分位"这类派生展示。

## 不适用

- 纯展示字段、纯单位换算（改 `field_units.py` + `screening-format.ts` 即可，见 RG3）；
- 只改文案/标签。

## 一句话总纲

> **比率类指标的风险不在分子，全在分母。**
> 分母错了不会报错，只会把结果放大十倍百倍，而且看起来"很有说服力"。

## 10 步清单（按顺序，每步都要留下可复现证据）

### 1. 先写清"这个指标回答什么问题、不回答什么问题"

写不出这句话就先别动手。示例（ROCE）：
回答「生意每元资本赚多少」；**不**回答「股票贵不贵」「能不能持续」。

### 2. 公式每一项 → 精确字段路径 → 打印 5 个样本手算核对

- ❌ 「净固定资产」→ 直译成 `balance_sheet.fixed_assets`（PPE）
- ✅ 「净固定资产」= 全部长期资产 = `total_assets - total_current_liabilities`
- 必做：手算 1 家，与 SQL 结果逐位对齐。

### 3. 公式含加总/相减，先验会计恒等式

- `流动资产 + 非流动资产 = 总资产`
- `资产 = 负债 + 权益`
- 违反率 0.01%–0.07% 可接受；超过 0.5% 说明取错列。

### 4. 用外部标杆校验量级（**最容易省、也最救命的一步**）

| 指标 | 标杆 |
|---|---|
| ROCE | 蒂芙尼 16% / 好市多 22% / 纳兰达组合中位 42% / Havell 52% |
| PEG | < 1 为便宜 |
| F-Score | 0–9 |
| Z-Score | 1.8 / 3.0 两条线 |

没有书/论文标杆的，用「行业常识 + 头部公司手工核算」。
**超出标杆一个数量级时，先怀疑分母，不要继续调公式。**

### 5. 检查分母是否会 ≤ 0，并决定怎么标注

- 必须写 `status`（如 `INVALID_DENOMINATOR`），CE 原值照常保留可复核；
- **不做截断、不设上限、不置空**——用户裁决："极值要么是对的要么是错的，对的就该显示，错的就去修"；
- ❌ 反面教材：`roe if abs(roe) <= 1.0 else None` 静默置空了 48 只真实 ROE > 100%。

### 6. 检查字段的历史覆盖率与跨年口径断点

例：`interest_expense` 2016 年只有 12.6% 覆盖；2020 新收入准则让销售费用率跳 −1.41pp；
`contract_liabilities` 2020 才有；2026Q3 不披露现金流量表补充资料（折旧摊销不可算）。

### 7. 检查特殊行业是否适用

- 金融股（119 只，市值占 21%）没有流动/非流动划分、没有"财务费用"行；
- 判据用 `sw_level1 IN ('银行','非银金融')`，**不要用 `csrc_l1`**（同花顺/指南针也在里面）；
- 排除的是"指标不适用"，不是"公司不好"——必须写进报告。

### 8. 派生域必须有重建触发，且快照重发要保全

两条都要：
1. `update.py` 里有重建步骤（不能是"一次性脚本"）；
2. `app/core/indicators/calculator.py::derived_snapshot_domains()` 登记列名 + 重建函数，
   由 `_derived_columns_guard()` 在两条发布路径上保全/重建/校验。

> 少了第 2 条 → 每次快照重发把新列清成 NULL（`reports/131` K5）；
> 只补整表路径 → 增量发布仍在清空（2026-11-17 实测）。

### 9. 筛选口径用「有效数据年数」，不用「上市年限」

算单年比率需要上一期数据：N 年历史只能算出 N−1 个值。
「上市满 5 年」实际只够 4 个值（K6，需求方自评"这 5 年是我拍脑袋想出来的"）。

### 10. 至少输出三个列位：历史中位 / 近期中位 / 最新值

三者背离就是信号：

- 10 年高 + 最新崩 = 正在恶化（智飞生物 36.9% → −66.4%）；
- 5 年 > 10 年 = 最近才好起来（天孚通信 18.5% → 25.8% → 48.4%）。

只给一个长中位数，越长的中位数越会掩盖正在崩塌的公司（K7）。

- [ ] 报告写清：口径、外部核验来源、为什么不选另一个口径、实测分布（中位/p90/上限）

## 常见错误对照表

| 症状 | 大概率病因 |
|---|---|
| 结果飞出 100%+ 或 ±10⁴% | 分母被改小（只取了 PPE / 剔了现金 / 单位错） |
| 中位数很长、最新值很惨 | 只给了长中位数，缺"最新值"列位 |
| 一批股票该有值却是 NULL | 用了护栏置空，或字段历史覆盖不足 / 行业不适用 |
| 筛选"能选中但筛不出结果" | 派生域冻结（没有重建触发），不是筛选器坏了 |
| 页面显示 100 倍 | 前后端单位口径漂移（pct vs percent） |
| 快照重发后指标变 NULL | 派生列没登记保全（R3） |
