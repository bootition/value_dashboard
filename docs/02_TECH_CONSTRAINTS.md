## 20. 技术约束汇总（用于架构决策）

### 20.1 性能约束
- 5000+股票 × 20条件 ≤ 5秒（10次中9次通过）
- 包含至少一个复合指标和一次当前行业排名
- 使用本地热数据

### 20.2 数据量估算
- 股票数量：~5000+ (沪深+北交所)
- 日线数据：5000 × ~250交易日/年 × 15年 ≈ 1875万行（每行含raw+qfq OHLCV）
- 财务报表：5000 × 4期/年 × 15年 = 30万报告行 × 500+字段
- PDF文件：5000 × 4期/年 × 15年 = 30万份PDF（冷归档）

### 20.3 接口约束
- CLI + Web 前端共享后端逻辑
- CLI 支持非交互运行 + JSON协议
- OpenCode 通过同一JSON协议调用
- 危险操作两段式确认（plan_id, 15分钟）

### 20.4 安全约束
- 个性化数据加密（用户口令）
- 凭据用Windows凭据保护机制
- 人工覆写与原始值分离存储

### 20.5 可替换性约束
- 数据源适配器必须可替换
- 必须保留原始溯源材料
- 多来源冲突时主来源优先
