## 3. 新增控制

### 3.1 入库和发布

- raw/QFQ 在同一 DuckDB 事务中写入；非 BSE 缺少 QFQ 时整只股票失败并进入重试列表。
- 资产负债表要求资产、负债和权益口径；利润表要求营收和归母净利润；现金流量表要求经营现金流。
- 不完整报表不写入完整报表语义，改为记录 `shell_row`。
- 指标快照先写 staging 表，全部计算成功并通过校验后才事务发布。

### 3.2 只读质量信号

`/api/data-status/summary` 已返回结构化 `data_quality`：

- 最新记录日期与最新完整日期；
- 价格、快照和计算日期；
- 未验证分红日期数量；
- 非法哈希与孤立批次数量；
- 未发布覆写与运行中作业数量；
- `FINANCIAL_SHELL_ROWS`、`SNAPSHOT_STALE`、`DIVIDEND_DATES_UNVERIFIED`、`LINEAGE_INVALID`、`UNPUBLISHED_OVERRIDES`、`STALE_RUNNING_JOBS` 等警告码。

正式旧 schema 上，缺少 `indicator_snapshot.calculated_at` 或 QFQ `turnover_rate` 不再导致只读页面 500；API 明确返回 `null`，不在读取过程中修改正式库。
