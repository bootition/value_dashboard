# 个股业务概览 P2 实施报告

## 1. 裁决

**有条件 PASS。** P2 独立低频业务概览域、东财 F10 适配器、更新与失败状态、详情 API 和前端研究展示均已实施。20 股有界探测中 18 只沪深样本字段可用，2 只北交所样本核心字段为空；北交所按 `missing` 展示，不伪造或降级填充。

## 2. 来源门禁

2026-08-10 对 20 只股票执行不落正式库的有界探测：

- 18 只沪深样本：`CompanySurvey` 简介/经营范围与 `BusinessAnalysis` 主营构成均可解析。
- 2 只北交所样本：接口可达但简介、经营范围、有效报告期和主营构成为空。
- 沪深样本主营构成可见产品、行业、地区三类；金融公司按来源实际情况可能只提供行业和地区。
- 解析器要求简介或经营范围至少一项有效；主营记录要求类型、项目名称和合法报告期，空壳记录一律 `missing`。

## 3. 实施范围

- 新增 `company_profile` 和 `business_breakdown` DuckDB 独立表，保存报告期、来源、抓取时间、原始哈希、置信度和批次。
- 新增 `eastmoney_f10` 独立适配器实例、0.5 秒请求间隔、独立路由和连接池。
- 单股资料与主营构成在同一事务发布；网络失败保留旧值并进入 retry，合法空响应保留旧值并进入 missing。
- 自动更新在价格与股票指标步骤后按月有界续传，每轮最多 20 只，自选股票优先；下一轮继续缺失或陈旧股票，不重复停留在首批。
- CLI 提供 `vd data business-overview` 的指定股票、全量、有界和只读状态入口。
- 详情页首屏展示精简业务概览、最近构成报告期和产品/行业/地区前列标签；经营章节展示最近报告期明细和溯源。
- 业务概览保持 `approximate`，无数据为章节内局部空态，不影响股票详情其他研究能力。

## 4. 隔离与验证

- 业务表不进入 `stock_meta`、价格、财报、`indicator_snapshot`、筛选基础池或 readiness。
- 独立回归：26 passed。
- 完整 S1 隔离回归：516 passed；最终熔断路由收紧后相关 42 项通过。
- Ruff：PASS。
- 前端 lint：PASS；node 测试 55 passed；组件测试 36 passed；production build PASS。
- 全部数据库测试使用 S1 隔离路径，未写正式 `data/`。

## 5. 剩余边界

- 正式库尚未执行全市场业务概览回填；默认自动更新将按每轮 20 只逐步续传。
- 北交所不承诺与沪深同等业务概览覆盖，免费源为空时保持 `missing`。
- P3 国债曲线和股息率利差、P4 历史统计尚未实施。
