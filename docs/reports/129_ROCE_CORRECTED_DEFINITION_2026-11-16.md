# ROCE（已动用资本回报率）口径更正 + 可研结论

> **本报告取代 `reports/128`。** 128 的可行性结论（数据支撑、覆盖够、口径可选）成立，
> 但**分母映射错了**，据此得出的「必须加三条重护栏」「219 只分母为负」「−8,311%~+21,285%」
> 全部作废。用户当场质疑："怎么会搞出负的 8000 多到正的 2 万多？这怎么可能？"
> 质疑成立——错在我的字段映射，不在指标本身。

---

## 1. 错在哪（一句话）

我把用户定义里的「**固定资产净值**」直接映射成了数据库列 `balance_sheet.fixed_assets`
（= 固定资产原值 − 累计折旧，即**厂房设备类 PPE**）。

**这个映射是错的。** 经典 ROCE 公式里的「固定资产」是资产负债表上
**「非流动资产」整段**（英文 *Fixed Assets* 一节，与 *Current Assets* 相对），
它包含固定资产、在建工程、无形资产、商誉、长期股权投资、使用权资产、递延所得税资产等
**全部长期资产**——不是只有 PPE。

用 PPE 当代替非流动资产，等于把商誉、无形资产、长期投资全部从分母里抽走：

- 伊利股份：商誉+无形资产等占了绝大部分长期资产，只算 PPE 时 CE 被压到 **−56 亿**（负分母）；
- 美年健康：资本几乎全在商誉里，PPE 只有 0.2 亿 → 分母 0.04 亿 → ROCE **21,285%**；
- 全市场 296 只分母 ≤ 0 —— 这些荒谬数字**全部是分母被抽空造成的**，与赚钱能力无关。

## 2. 用户的定义本身已经自证了口径

用户原文给的是**同一个指标的两个写法**：

| 写法 | 中文 |
|---|---|
| ① 息税前利润 ÷ 当期平均已动用资本 | 抽象定义 |
| ② 息税前利润 ÷（净营运资本 + 固定资产净值） | 展开定义 |

而会计恒等式是：

```
净营运资本 + 非流动资产 = (流动资产 − 流动负债) + 非流动资产 = 总资产 − 流动负债
```

两种写法要相等，**「固定资产净值」必须等于「非流动资产」**。
用 PPE 代入，两者根本对不上——这本身就是我该立刻发现的信号。

### 2.1 教科书里的三种等价写法（外部核验）

| 出处 | 原文 | 译 |
|---|---|---|
| AAT（Association of Accounting Technicians）论坛权威答复 | "Capital Employed … is the same value as the **Fixed Assets + Net Current Assets** or the **Total Assets less Current Liabilities**" | 固定资产 + 净流动资产 ≡ 总资产 − 流动负债 |
| 12manage《Versions of ROCE Formula》 | 1. EBIT / Capital Employed　2. EBIT / (Total Assets − Current Liabilities)　3. EBIT / (Equity + Non-current Liabilities)——"They all mean exactly the same and are mathematically identical" | 三种写法数学恒等 |
| 印度博士论文（ROCE 章节） | "Net capital employed = Gross capital employed − Current liabilities **or Fixed Assets + Net working capital**" | 净资本占用 = 固定资产 + 净营运资本 |
| 中文实务（财新·贝乐斯《ROCE—独特的回报率标准》） | "使用资本是**固定资产加无形资产及商誉**，再加净运营资金" | 明确把无形资产及商誉并进长期资产 |

关键在英文 *Fixed Assets* 一词：它是**资产负债表的一个大区**（对 *Current Assets*），
不是中国准则下狭义的「固定资产」。中文旧译把这个区段直接译成「固定资产」，
今天再照着列名 `fixed_assets` 去取数，就必然抽空分母。

## 3. 修正后的口径（定稿）

```
EBIT_TTM = TTM(利润总额 + 财务费用)                       # 与 indicator_ext.ebit 同源
已动用资本 CE = 总资产 − 流动负债                          # ← 修正点
             = 净营运资本 + 非流动资产                      # 同一件事
平均 CE  = ( CE(本期) + CE(去年同期) ) / 2
ROCE     = EBIT_TTM / 平均 CE                             # 小数比例，0.203 = 20.3%
```

**为什么用「总资产 − 流动负债」而不是「非流动资产 + 净营运资本」直接相加**：
两者数学恒等（已实测，见 §4.1），但前者只需要两个必填科目，缺失面更小
（后者要凑齐 `total_non_current_assets` / `total_current_assets` / `total_current_liabilities` 三个）。

## 4. 修正后的实测（正式库 2026-11-16 只读，活跃池 5,575 只）

### 4.1 先验恒等式（证明两种写法确实同值）

| 校验 | 结果 |
|---|---|
| `流动资产 + 非流动资产 = 总资产`（容差 0.1%） | **353,239 / 353,665**（99.88%） |
| `(总资产 − 流动负债) = 非流动资产 + 净营运资本`（容差 1 元） | **352,693 / 353,655**（99.73%） |

### 4.2 修正前后对比

| 项 | 旧（PPE 错误口径，reports/128） | **新（总资产 − 流动负债）** |
|---|---|---|
| 可算出有效值的只数 | 5,165（92.65%） | **5,367（96.27%）** |
| 分母 ≤ 0 的只数 | **219** | **22** |
| \|ROCE\| > 100% 的只数 | 41（>200% 还有 6，最大 21,285%） | **4**（最大 228.6%） |
| p05 / 中位 / p95 | −24.8% / 6.8% / 35.8% | **−16.8% / 4.6% / 20.9%** |
| p01 / p25 / p75 / p99 | — | **−54.2% / −0.8% / 9.7% / 41.1%** |
| 最小 / 最大（未加比例护栏） | −8,311% / +21,285% | **−694.8% / +228.6%** |
| 最小 / 最大（加 `|ROCE| ≤ 300%` 后） | −298.9% / +243.0% | **−235.7% / +228.6%** |
| 与 ROE 相关系数 | 0.78 | **0.896** |
| 与 ROIC 相关系数 | 0.68 | **0.763** |
| 中位数对照 | ROCE 6.9% vs ROE 3.7% vs ROIC 3.4% | **ROCE 4.4% vs ROE 3.6% vs ROIC 3.1%** |

**"负的几十到正的几十"——正是用户说的那个量级。** p05 −16.8%、p95 +20.9%、中位 4.6%。
ROCE > 20% 的有 **301 只（5.6%）**，这个比例对「投 100 赚 20」的筛选阈值来说是合理的。

残留的极端值不再是系统性问题：最小 −694.8%（`300472 ST新元`，总资产≈流动负债、
资本占用≈0）与最大 +228.6%（`300169 天晟新材`，CE 仅 1 亿）都是**真的分母趋零**，
属于少数个案，加一道 `|ROCE| ≤ 300%` 就只剩 4 只被剔除。

### 4.4 为什么不用「扣现金」的运作口径

实务上还有一种更严格的版本：`CE = 总资产 − 流动负债 − 货币资金 − 交易性金融资产`
（财新那篇文章的口径，排除现金这类「不产生经营利润」的资产）。实测对比：

| 口径 | 分母 ≤ 0 | p05 | 中位 | p95 | 最大 | >100% 只数 |
|---|---|---|---|---|---|---|
| **标准（总资产 − 流动负债）** | **22** | −16.9% | 4.6% | 20.9% | **228.6%** | **4** |
| 扣现金版 | 136 | −23.5% | 6.4% | 40.2% | **2,008.1%** | 41 |

扣现金版会把**现金充沛的好公司**分母打空：五粮液现金 1,117 亿 ≈ 其 CE 1,214 亿，
扣完只剩 97 亿 → ROCE **618%**。所以**不采用**扣现金版作为主口径；
用户定义里的「净营运资本」本身含现金，标准式才是忠实实现。

## 8. 本轮教训（已登记 `ops-knowledge-base` D52）

1. **字段名直译 = 高发事故**。英文 *Fixed Assets* / 中文旧译「固定资产」是**报表大区**
   （= 非流动资产），不是 `balance_sheet.fixed_assets`（PPE）。
   **判据**：任何"加总后应当等于某恒等式"的公式，落库前先用恒等式自查；
   本次若先跑 `流动资产 + 非流动资产 = 总资产`，5 分钟就能发现映射错。
2. **分布形状是口径正确性的一阶检验**。比率类指标出现 −8,311% / +21,285% 这种量级，
   先怀疑分母，别急着加护栏把锅甩给"公司特殊"。
   正确的做法是：先问"教科书里这个分母到底指什么"，再谈护栏。
3. **护栏数量是口径好坏的体温计**。同一指标从 3 条重护栏（219 只分母为负）降到
   5 条轻护栏（22 只分母为负、4 只比例护栏），说明第二次才是真口径。
4. **`reports/128` 的错误结论保留存档不删**，标 `superseded`，避免下次有人再踩同一个坑。
