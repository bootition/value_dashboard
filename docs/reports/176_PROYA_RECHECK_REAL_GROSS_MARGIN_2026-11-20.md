## 3. 新证据：用「销售费用率」把生意模式量化

用户说的「**它必须花很多钱投在营销上面**」，这个是可以算的。库里 `income_statement` 有 `selling_expenses` 和 `rd_expenses`，之前从没用过。

### 3.1 定义

```
真实毛利率 = 毛利率 − 销售费用率
销售/毛利  = 销售费用率 ÷ 毛利率   （维持 1 元毛利要花多少销售费用）
```

**含义**：毛利率是"生产出来能卖多贵"，扣掉销售费用才是"**不花钱推、消费者自己愿意买的部分**"。
**品牌力强的公司，销售费用率极低**（茅台 4.3%、法拉电子 1.1%）；**靠投放的公司，销售费用率极高**（珀莱雅 49.6%）。

### 3.2 关键对比：珀莱雅 vs 海天味业

| | **海天味业** | **珀莱雅** | 差距 |
|---|---:|---:|---|
| 毛利率 | 40.2% | **72.8%** | 珀莱雅看起来高 32.6pct |
| **销售费用率** | **6.7%** | **49.6%** | **珀莱雅是海天的 7.4 倍** |
| **真实毛利率** | **33.5%** | **23.2%** | **海天高 10.3pct** |
| 销售/毛利 | 16.7% | **68.2%** | 珀莱雅每赚 1 元毛利要花 0.68 元去卖 |
| 研发费用率 | 3.2% | **2.0%** | 海天研发投入比例反而更高 |
| OCF/净利 | 0.94 | 0.81 | 海天更好 |
| ROCE | 34.2→21.9 | 24.7→27.4 | 海天曾经更高，但在降 |
| **真实毛利率全表排名** | **114 / 440** | **210 / 440** | **珀莱雅低 96 名** |

**用户的判断完全正确**：
- **海天的问题是「贵 + 增长停滞 + ROCE 腰斩」——是"公司状态"问题**
- **珀莱雅的问题是「生意模式」问题——72.8% 的毛利率是假象，扣掉投放只剩 23.2%，比格力（23.9%）还低**

## 5. 修正后的结论

### 5.1 珀莱雅：**普通公司**（原判"次级"过宽）

| 判据 | 数值 | 判断 |
|---|---|---|
| 毛利率 | 72.8% | 看起来顶级 |
| **销售费用率** | **49.6%** | **全表最高之一** |
| **真实毛利率** | **23.2%（第 210/440）** | **比格力还低** |
| 研发费用率 | **2.0%** | 低于海天（3.2%） |
| OCF/净利 | 0.81 | 不及格（史密斯 Q3 线 0.95） |
| 净利增速 | 23.1% → **5.0%** | 投放换来的增长已经到顶 |
| 分红率 | 27.5% | 低 |
| 9 人票数 | **普通 5 / 次级 4** | **没有一个人判它好生意** |

**结论：珀莱雅 = 普通公司。它的高毛利是"投流买来的品牌税"，生意模式本身不成立。**

### 5.2 海天味业：**次级**（维持原判）

**用户说得对——海天"除了贵、市盈率高，没有什么问题"：**

| 判据 | 数值 | 判断 |
|---|---|---|
| 毛利率 | 40.2% | 中性 |
| **销售费用率** | **6.7%** | **极低，说明品牌力真实** |
| **真实毛利率** | **33.5%（第 114/440）** | 干净 |
| OCF/净利 | 0.94 | 及格 |
| **ROCE** | **34.2 → 21.9** | **唯一硬伤：腰斩** |
| 五年净利 CAGR | 1.9% | 增长停滞 |
| 9 人票数 | **次级 8 / 顶级 0** | 一致 |

**所以海天是"生意模式干净、但回报率在掉 + 增长停滞"→ 次级。**
**珀莱雅是"生意模式不成立"→ 普通。**

**两者不在同一档，用户的直觉正确。**

## 6. 这个新指标还纠正了三个我之前的判断

### 6.1 格力 vs 美的：格力的生意模式其实更好

| | 格力 | 美的 |
|---|---:|---:|
| 销售费用率 | **4.9%** | 9.4% |
| **真实毛利率** | **23.9%（第 204）** | **16.7%（第 301）** |

**但 9 位大师里，美的拿了 3 票顶级，格力 0 票。**
差距不在生意模式，在**分红年限（格力 8 年 vs 美的 13 年）和增长（美的 +10.1% vs 格力停滞）**。
**这说明"生意模式"和"投资价值"是两件事——这一点我要说清楚。**

### 6.2 今世缘的真实毛利率（52.1%，第 27）比海天还高

**所以今世缘不是"生意差"，是"生意好但天花板低"。**
它的销售费用率 23.1%，是茅台（4.3%）的 5.4 倍、汾酒（10.6%）的 2.2 倍——**这就是"地域品牌"的量化证据：必须靠渠道费用才能卖出去。**

### 6.3 法拉电子它毛利率只有 32.3%，却排第 134

**因为销售费用率只有 1.1%（全表最低）。** 这是典型 B2B 元器件生意——客户认规格不认广告。
**这解释了为什么 5 位大师给它顶级：它的护城河不在品牌，在转换成本。**

## 7. 但也要说清这个指标的局限

**单用"真实毛利率"会得出荒谬结论：**

| 公司 | 真实毛利排名 | 但它的问题 |
|---|---:|---|
| 同花顺 | 2（80.3%） | 收入跟 **A 股成交量**绑定，PB 17.65 |
| 东方财富 | 3（75.0%） | **大股东占款 1.97%**（482 家里唯一） |
| 江苏金租 | 5（69.4%） | 金融租赁，**杠杆经营**，不可比 |
| 天齐锂业 | 15（60.7%） | **周期股**，去年还在亏 |
| 巨人网络 | 14（60.8%） | **游戏产品周期** |

**所以它只能回答"这门生意卖东西费不费钱"，不能回答"它十年后还在不在"。**

**正确的用法**：把它当**必要不充分条件**——
- **真实毛利率 <25%（如珀莱雅 23.2%）→ 基本不可能是顶级生意**
- **真实毛利率 >50% 且 销售费用率 <15% → 品牌/技术护城河是真的**（茅台 85.6%/4.3%、老窖 70.9%/12.6%、法拉 31.2%/1.1%）

## 8. 三句话

1. **珀莱雅降为普通公司**：72.8% 的毛利率是假象，**销售费用率 49.6%（全表最高之一）**，扣掉后真实毛利率只有 **23.2%，排 210/440，比格力还低**。9 位大师 5 票普通、4 票次级，**没有一个人说它是好生意**。
2. **海天味业维持次级**：销售费用率只有 **6.7%**、真实毛利率 **33.5%（第 114）**——**生意模式确实干净**，它的硬伤是 **ROCE 34.2→21.9 腰斩 + 五年 CAGR 1.9%**。**用户说的"除了贵没有别的问题"是准确的。**
3. **新增了一个可复算的判据**：`真实毛利率 = 毛利率 − 销售费用率`。**它把"高毛利"和"高毛利且不用花钱卖"分开了**——这是区分珀莱雅和海天的关键。
