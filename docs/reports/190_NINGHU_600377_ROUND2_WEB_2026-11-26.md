# 宁沪高速第二轮：决定估值的是行政审批口径，不是财务预测

> **第一轮**（`reports/176`）：2 买 / 5 观察 / 1 不买，买点 **9.49–11.85 元**，同时用有限期 DCF 给出内在价值 **2.78–8.27 元**。
> **本轮**：判决变成 **0 买 / 7 观察 / 1 不买（费雪）**。买点下修到 **7.80 / 6.90 / 6.10 元**。
> **本轮最大的发现**：**第一轮的"内在价值 2.78–8.27"不是一个价值区间，而是一个三参数网格的对角线两端**——而且**第一轮的买点 11.85 比它自己的 DCF 上沿 8.27 还高 43%**。
> **性质**：研究结论，不构成投资建议。

## 2. 四个核心问题的答案

### 2.1 有限期 DCF：第一轮的 2.78–8.27 是个"网格对角线"

**核验官把第一轮的公式反推出来了**：

```
第一轮 DCF = FCFF 60.7 亿 × 年金系数(n, r) − 净负债 304.3 亿，再 × 75.75% 的账面权益比例

代入 22 年 / 7%：60.7 × 11.0612 = 671.4 − 304.3 = 367.1 × 75.75% = 278.1 ÷ 50.377 亿股 = 5.52 元  ← 与报告吻合
代入 15 年 / 9%：→ 2.78 元
代入 32 年 / 6%：→ 8.28 元
```

→ **所以"2.78–8.27"不是价值区间，是一个三参数网格的"最短年限 × 最高折现"到"最长年限 × 最低折现"的对角线两端。中间那个 5.52 元才是它的基准。**

→ **而且它做了两次扣减**：净负债已经通过利息在 FCFF 里扣过一遍，又从企业价值里扣一次；再乘 75.75% 的权益比例，**等于把少数股东权益和净负债各打了两次折**。8/8 大师一致指出这一点。**第一轮 2.78 元的下限不合理，8.27 元是合理保守值。**

**8 位大师独立重做后**：**8.1 / 8.1 / 9.3 / 9.6 / 9.8 / 10.0 / 10.0 / 10.0，均值 9.36、中位 9.70、极差仅 ±10%**（口径高度一致：归母或 CFO 派生 FCFE × 零终值年金，只有格林布拉特用 FCFF 扣净负债）。

**一个必须点破的层次**：**第一轮八位大师自己的 IV 中位约 10.6 元，本来就高于主控 DCF 上沿 8.27 元。** 本轮他们给 9.70，**相对他们自己第一轮的数字是下修约 11.7%**（巴菲特 −5.7%、芒格 −13.0%、段永平 −20.0%、李录 −19.0%、马克斯 −22.5%，只有费雪 +10.1%）。
→ **所以"本轮集体上修内在价值"是错觉：真实发生的是"大师们下修了 12%，同时集体否决了主控层 2.78–8.27 的方法论"。这两件事方向相反，不能混成一句"上修"。**

### 2.2 A/H 溢价 48.64%（今日 51.8%）：A-only 投资者**没有可执行的买点**

| | A 股 | H 股 |
|---|---:|---:|
| 价格 | **14.41 元** | 11.09 HKD × 0.856 = **9.49 元** |
| 溢价 | — | **按 11-16 是 48.64%，按今日 A 是 51.8%** |
| 股息率（毛） | **3.40%** | **5.16%** |
| 股息率（内地个人税后） | **3.40%**（持股 >1 年免税） | **4.13%**（港股通 20% 红利税） |

**核验官的算术（这是本轮最有力的一段）**：
> **A 要跌 45.9% 才到 T1（7.80），而同一时间 H 只要跌 17.9% 就到等值（9.11 HKD）。**
> **若 A 真跌到 7.80 而 H 保持 9.49 元，A 反而比 H 便宜 17.8%——这说明 A 的 7.80 只在"A 相对 H 单独多杀 30 个百分点"时才出现，而这种杀法只可能来自 A 股的流动性事件，不可能来自基本面。**

→ **对 A-only 投资者，正确的表述不是"等到 7.80"，而是"要么等到 A/H 溢价收敛到 20% 以内（此时 A ≈ 11.4 元，仍高于合理价值 9.4 元，还不够），要么承认这单不做"。**
→ **A-only = 0 仓位，不买。7.80 只作为"若发生系统性错杀"的记录价，不构成等待计划；H 侧则挂在 9.11 HKD 以下（−17.9%），可执行。**

**芒格给 A 股溢价定的合理上限**：**"A 股相对 H 的合理溢价，我最多给 10%–15% 的流动性/税制补偿，对应 A 约 10.4–10.9 元；现价仍高出 32%–39%。"**

### 2.3 建造期收入 35.33%（2026H1）/ 约 40.2%（2025）：**不虚增利润，只虚增营收**

**这个坑必须说清楚，因为它是本轮唯一一处"看起来该扣、其实不该扣"的地方**：
- **建造期收入与建造成本大致对冲，毛利接近零，不进归母** → **PE 15.75 的分母 46.1 亿本来就是干净的**
- **不能从归母里再扣一次建造收入**——那是把"营收虚增"误当"利润虚增"
- **该还原的是收入口径**：2025 年剔除建造后真实营收约 **159.9 亿**，**真实毛利率约 38.2%、净利率约 28.8%**；2026H1 还原后毛利率约 53.5%、净利率约 41.6%（H1 有季节性，不能年化）
- **毛利率从 54.59%（2019）掉到 26.28%（2024），主要是收入 mix 变化（建造收入并表），不是收费公路生意崩坏**

**若硬要量化建造业务的利润贡献**：格林布拉特假设 1%–3% 净利率取 0.8 亿 → 真实主业利润 44.5 亿、EV/EBIT 15.31x。核验官复核：**若 2% 净利率，2025 年 81.6 亿建造收入对应税后约 1.2 亿，归母从 46.1 降到 44.9，PE 从 15.75 升到 16.17，影响仅 +2.7%，可忽略。**

→ **建造期收入真正的含义是：35%–40% 的建造收入意味着更多资本开支、更多债务、更多未来折旧——它是"投入"，不是"利润"，所以不能给更高 PE。**

### 2.4 ROCE 从 17.86% 崩到 8.75%：改扩建投入期 + 已经发生的结构性下降

```
CE  从 290.4 亿（2016）→ 849.1 亿（2025），+192%
EBIT 从  49.2 亿（2016）→  69.4 亿（2025），+41%
增量资本回报 = (69.4 − 49.2) / (849.1 − 290.4) = 20.2 / 558.7 = 3.6% 税前、2.7% 税后
```

→ **低于债务成本，更低于 8% 门槛。**

**巴菲特的分档判断**："**既有改扩建投入期的时点因素，也已经是资本回报的结构性下降。改扩建完成后合理 ROCE 约 10%–11%，乐观 12%，回不到 17.86%——老路产的低成本、长剩余期不可复制。除非项目级 IRR 明显高于 8%，新增资本继续稀释价值。**"

**注意一个关键区分**：**CE 涨 192% 里有一部分是"建造期"会计处理**（在建工程与建造收入同时进表），所以**账面 ROCE 的下降幅度有一块是会计性的**。但**增量资本回报 3.6%** 这个数是真实的——不管会计怎么记，钱投出去了、EBIT 只多了 20.2 亿。

## 3. 本轮题眼：改扩建能否续期，值 2.3 倍

**核验官算的两个端点**：

| 情形 | 假设 | 每股 | A 14.41 的位置 | H 9.49 的位置 |
|---|---|---:|---|---|
| **不能续期** | 加权剩余 **12 年**、8% 折现、终值严格为 0 | **6.90 元** | **高 109%** | **高 38%** |
| 中间态 | 加权剩余 **15 年**、8%、终值 0 | **7.83 元** | 高 84% | 高 21% |
| **能滚动续期** | 改扩建**法定**续期 25–30 年（沪宁改扩建批文续到 2045 年以后且可再续）→ 资产变准永续，合理 PE = 1/(8%−2%) = 16.7 倍 | **15.98 元**（0.957 × 16.7） | **反而"合理偏低"** | 折价 41% |

→ **6.90 ↔ 15.98，2.3 倍，而决定它的是一条行政审批口径，不是一个财务预测。**

**核验官的结论**：**"这是唯一能同时翻转多空两侧的数据。在拿到逐路到期表之前，任何买点都只是价格，不是买点。"**

**三个反解（证明现价需要什么条件才成立）**：
- 要让 14.41 在 8% 下成立，**FCFE 必须做到 726 / 8.5595 = 84.8 亿（+84%）**
- 或年限拉到**约 50 年（r = 6%）**
- 或直接按**永续 6.35% 要求回报**
- **三条都没有证据支持。**
- **现金口径更残酷：14.41 ÷ 0.49 = 29.4 年才靠分红回本（不计税、不折现）。**

## 5. 第一轮的两处严重错误（必须记录）

| # | 错误 | 事实 |
|---|---|---|
| 1 | **买点高于自身估值** | **第一轮买点上沿 11.85 元，比它自己算的 DCF 上沿 8.27 元还高 43%**。既然自己算出来上限只值 8.27 元，就不该在 9.49 元以上买。**这是第一轮最严重的自相矛盾**，本轮 8 份全部把它修掉了（连最保守的李录 7.44 都低于第一轮下沿 9.49） |
| 2 | **"内在价值区间"其实是网格对角线** | 2.78–8.27 分别是"15 年 × 9% 折现"与"32 年 × 6% 折现"两个极端，**中间基准 5.52 元才是它的结论**。而且它**做了两次扣减**（净负债在 FCFF 里扣过利息、又从 EV 里扣一次；再乘 75.75% 权益比例把少数股东权益也打两次） |

**另外纠正数据包自己的一处复述错误**：数据包把第一轮写成"2 买 / 6 观察"，**实际是 2 买 / 5 观察 / 1 不买（斯利普）**。本轮**斯利普从"不买"升到"观察等待"，是全场唯一一次判决上修**——如果按数据包口径记成"6 观察→7 观察"，这次上修就被抹掉了。

**还要点破一个标签通胀**：**7 份贴"观察等待"，但其中 5 份的首档价距现价 −39% 至 −48%**（李录 −48.4%、格林布拉特 −45.9%、马克斯 −40.3%、巴菲特 −39.6%、费雪 −38.9%）。**这个标签的实际含义已经是"不买，除非崩盘"，和费雪的"不买"没有操作区别。**

**本轮仍有 3 处"买点高于自己 IV"的老毛病未修**：**芒格 T1 9.50 对 IV 10.0 只有 −5% 折扣、格林布拉特 T1 7.80 对 IV 8.1 只有 −3.7%** —— 都不构成安全边际；**斯利普把"A 等值 10.06"写在 IV 10.0 之上（+0.6%）**，靠"只买 H、A 侧永不挂单"来自洽，本质是把 A 列当摆设。

## 6. 买入方法与退出

### 6.1 方法

1. **H 优先，且 A/H 独立触发**：H 可在 9.11 HKD 独立下单，即使 A 还在 12 元。
2. **T1 的第 ④ 条（逐路到期表 + 加权剩余 ≥15 年）是硬门槛**：**没有它，价格到了也不买**。这是本轮唯一一条"数据不齐即作废"的条件。
3. **价格 + 基本面双触发**，三档间隔 ≥ 一个完整财报季。
4. **A-only 投资者：0 仓位**。不要用 7.80 当"等待价"，那是把买点画在自己永远等不到的地方。
5. **总仓 6%（H 为主）**，不融资、不摊薄。

### 6.2 停止买入的硬条件

| # | 条件 | 当前 |
|---|---|---|
| 1 | **加权剩余特许期 <12 年，且无续期/补偿安排** | 未知（**最大缺口**） |
| 2 | **DPS <0.47 或派息率跌破 50%** | 0.49 / 53.73% |
| 3 | **通行费收入连续两年负增长** | 2025 +0.29% |
| 4 | **净负债/EBITDA >5.0** | 待查 |
| 5 | **建造收入占比连续两年 >45%**（说明在建工程持续放大但回报未现） | 2025 约 40.2%、2026H1 35.33% |
| 6 | **CFO <55 亿** | 2025 67.6 亿 |

### 6.3 退出条件

1. **特许期证伪**：拿到逐路到期表，加权剩余 <8 年且无续期安排 → **不计价格清仓**。
2. **资本配置失败**：改扩建完成后 ROCE 仍 <8%，或项目可研 IRR <8% → 减仓。
3. **政策风险**：通行费降价或免费政策扩大 → 重估。
4. **分红政策变化**：派息率跌破 40%，或停发 → 卖出（这只票一半的价值在分红）。
5. **估值兑现**：A >12 元或 H >14 HKD（约 1.2 倍 IV 中枢）且盈利未上修 → 减仓。
6. **净负债恶化**：净负债/EBITDA >5 倍，或进行大额股权融资 → 卖出。
