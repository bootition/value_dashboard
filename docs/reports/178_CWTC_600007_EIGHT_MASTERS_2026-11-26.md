## 2. 唯一自洽的锚：27 年有限地权 + 净现金 + 留存 FCF

审计把 8 份报告的锚逐个拆开后，只剩一个自洽的：

| 参数 | 值 |
|---|---|
| 折现对象 | 股东可得的自由现金流（FCF 15.0 亿，**含留存 4.2 亿**——PAYOUT 87.66%，留存 12.34%） |
| 期限 | **27 年**（有限地权，非永续） |
| 折现率 | 8.0% |
| **每股价值** | **21.95 元** |
| **现价 21.68** | **隐含要求回报 8.15%** |

**为什么 cap rate 锚（33–40 元）不能用**：
- **资产重估对 PB 判据完全无效**——重估 3 倍后：PB 从 2.266 降到 1.22、ROE 从 12.86% 降到 6.86%、**PE 一动不动**。也就是说重估只是把"分母变大"，不增加一分钱现金流。
- 更要命的是：**"55.2 亿成本法账面被低估"这件事对股东零价值**——不卖、不抵押、不分拆，重估的钱永远拿不到；变现还要交 35–45% 的税（土地增值税 30–60% 累进 + 25% 所得税）。按 NOI 20.29 ÷ 6% = 338 亿 EV，扣负债再扣 40% 处置税后 → **约 21.5 元 = 现价**。**市场不傻，它给的就是"可实现现金流"的价格。**

**为什么 PB 2.266 可以定量判断贵不贵**：
`PB = (ROE − g) / (r − g)`，取 **g = SGR = 留存率 12.34% × ROE 12.86% = 1.57%**：

| 要求回报 r | 合理 PB | vs 现价 2.266 |
|---|---:|---|
| 8.0% | **1.74** | 贵 30% |
| 8.5% | 1.61 | 贵 41% |
| 9.0% | 1.51 | 贵 50% |
| 10.0% | 1.33 | 贵 70% |
| **6.5%** | **2.27** | **刚好等于现价** |

→ **只有当你的要求回报 ≤6.5% 时，2.266 才不贵。** 而 10Y 国债是 1.59%，把 6.5% 当要求回报意味着只要求 4.9pp 的股权风险溢价。

**反方最强一击**：把"永续"换成"27 年"，8% 要求回报下公允价从 **19.86 → 16.69（−16%）**；反解现价 → **r 只有 5.01%**。**这才是本票真正的风险点，不是"PB 太高"。**

## 5. 买入方法

### 5.1 三档 + 期限/分红双门槛

| 触发路径 | 条件 | 动作 |
|---|---|---|
| **价格触发**（主） | 触及 S1–S3 | 执行该档，同一档只打一次，两档间隔 ≥ 一个完整财报季 |
| **经营验证**（辅） | ① **单季营收同比连续两季 ≥0**（现 −5.8%）；② DPS ≥1.07（不再下调）；③ payout ≤90% 且 FCF 覆盖分红 ≥1.3x（现 87.66% / 1.39x ✓）；④ **capex/D&A ≥30%**（现 19% ✗） | 可在高一档价位提前执行下一档的 1/2 |
| **禁止** | 出现租金/出租率结构性恶化证据 | 冻结 |

- **首笔 2%，上限 8%**（8 人给 5–12%，中位 8%）。
- **不再上调仓位上限的理由**：收入端（出租率、租金、租约到期结构、北京 CBD 空置率、投资性房地产公允价值）**库内全无**；信息不足时仓位就是安全边际。

### 5.3 退出条件

1. **估值退出**：股息率 <3.5%（≈30.6 元）或 PB >3.20 减半；股息率 <3.0%（≈35.7 元）或 PB >3.65 清仓。
2. **分红契约退出**：DPS 连续两年下调或 payout 主动降到 <60% → 清仓（分红是持有它的唯一理由）。
3. **逻辑退出**：物业租赁及管理收入连续 3 年下滑且综合毛利率跌破 52% → 清仓（定价权没了）。
4. **期限退出**：若核心地块剩余年限 <20 年而股价未折价 → 卖出（消耗性资产必须随钟表折价）。
5. **资本配置退出**：capex/营收 >15% 连续两年，或有息/权益 >40%（开始"海螺化"）→ 减仓至 1/3。

### 6.2 方法论自省（本轮最重要的一条）

**我的 DATA_COOKBOOK 造成了框架植入**：R4 给了"cap 4.5%–6.0% → 30.6–43.5 元"和"隐含量化 cap 5.63%"的示范表格，结果 **8 份报告里有 6 份引用了同一个「cap 5.5% → 33.6 元」的数字**，把它当作独立发现。**两份"买"的票实际上同源，不构成 2 个独立证据。**

→ **对后续流程的约束（已写进 KB §34 `I-COOKBOOKBIAS`）**：cookbook 只能给**配方、口径、陷阱**，**不许给带方向的结论性数字**（如"NAV 33.6 元"）。凡是 cookbook 里出现"某法给某个价格"，下一轮必须删掉。
