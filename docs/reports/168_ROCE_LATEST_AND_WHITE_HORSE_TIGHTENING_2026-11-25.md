## 2. 开放 `roce_latest`：为什么这是「缺一条腿」而不是「少一个选项」

`roce_latest`（最近一年年报 ROCE）一直被登记为"详情页现况对照"，不在
`SNAPSHOT_COLUMNS`，因此 `_is_known_field('roce_latest')` 判 `False`：

- **条件 JSON 写不出**「当期 ROCE 低于自身 10 年中位」；
- 于是周期股判据只剩 **PB 分位** 一个位置信号 —— 它分不清
  「周期底部便宜」与「结构性衰退便宜」；
- 而 DSL 侧本来就能写（`INDICATOR_METADATA` 里有），形成"DSL 能、筛选页不能"的分裂。

改法（`app/core/screening/engine.py`）：白名单加 1 项。保存期与运行期共用
`_is_known_field_name()`（AGENTS R1 单一入口），所以只需改一处；
`field_units.py` 早已把 `roce_latest` 登记为 `pct`（小数比例），
与 `roce_10y_median` 同族，`right_field` 比较直接合法。

回归：`tests/regression/test_roce_latest_screenable.py`（4 例：白名单 / 保存期校验 /
条件编译成 `roce_latest < roce_10y_median` / `/indicators` 下发且 `unit=pct`）。

## 3. 白马股三次收紧的实测数据

两支撑 —— 成长支（高成长 + 高质量）、周期支（穿越周期 + 位置在底 + 扛得住）——
**各自都要求"长期资本回报"，这才是"白马"的本义**（长期绩优），所以 v3 把
`roce_10y_median` 提到成长支上，与周期支形成对称。

### 3.1 周期支变体（引擎实测）

| 变体 | 条件差异 | 只数 |
|---|---|---|
| V0 基线 | PB≤30分位 / 市值≥300亿 / ROCE10y≥10% / 负债≤60% / 有息≤35% / 分红≥5年 / CFO≥0.5 | 59 |
| **V1** | + `roce_latest < roce_10y_median`（不在景气顶） | 49 |
| **V2（采用）** | V1 + 连续分红 **≥8 年**（跨过一轮完整周期） | **46** |
| V3 | V1 + PB≤20 分位 | 37 |
| V4 | V2 + PB≤20 分位 | 36 |
| V5 对照 | 只加分红≥8（不加周期位置） | 55 |

选 V2 的理由：周期位置确认（V1）是**判断质量**的核心——它把"盈利被周期压住"
和"公司变差"分开；分红≥8年是**存续能力**的核心。V3/V4 进一步收 PB 只是数量取舍，
没有独立理由，故不叠加（避免为凑数量调参）。

### 3.2 成长支变体（引擎实测）

| 变体 | 条件差异 | 只数 |
|---|---|---|
| G0 基线 | 市值≥100亿 / ROE≥15% / 毛利≥30% / 净利CAGR5≥15% / CFO≥0.8 / 负债≤50% / 股息≥1% / 0<PE≤40 | 37 |
| **G1（采用）** | + `roce_10y_median ≥ 15%`（穿越周期回报，而非当期 ROE） | **18** |
| G2 | G1 + 净利CAGR5≥20% | 11 |
| G3 | G1 + 毛利≥40% | 13 |

### 3.3 合并（OR）结果

| 版本 | 成长支 | 周期支 | 合并 | 自选分组 |
|---|---|---|---|---|
| v1（`reports/167`） | 37 | 59 | 91 | 91 |
| v2 | 37 | 46（V2） | 82 | 82 |
| **v3（当前）** | **18**（G1） | **46**（V2） | **63** | **63** |

v3 名单前 12：古井贡酒、中信特钢、双汇发展、神火股份、华东医药、山西焦煤、华润三九、
分众传媒、华峰化学、太阳纸业、电投能源、华明装备。

> **代价必须说清**：`roce_10y_median` 要求拿满 10 年年报，所以 v3 天然排除
> 上市不足 10 年的公司（例如胜宏科技、兴齐眼药这类在 G0 里、在 G1 外）。
> 这是"长期绩优"定义的必然后果，不是 bug；若要覆盖新生代白马，应另建一支
> （例如"上市 5–10 年 + 5 年 ROCE 中位≥15%"），而不是放宽 10 年窗口。
