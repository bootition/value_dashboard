# 国债需求探索重置说明

用户明确表示尚不清楚“股息率与长期国债收益率比较”所需的国债定义、期限、口径及产品用途。因此此前将记账式国债、第五页面、日终双口径展示写作已确认需求的结论不成立。

本次撤回所有未充分讨论的国债 PRD 条款与开发计划。`reports/65` 中的数据源和架构风险调研事实可供后续参考，但不构成当前需求或实施授权。

下一步是完成概念说明和需求发现，至少确认：比较的投资问题、国债收益率基准期限、股息率口径、使用频率、展示方式和是否需要自动化计算。确认后再修订 PRD 和制定实施计划。
