# 国债曲线与股息率利差 P3 实施报告

## 1. 裁决

**PASS。** 财政部-中国国债收益率曲线独立基准域、TTM 已实施股息率与九期限利差、详情页国债比较、筛选字段与导出溯源均已实施并通过门禁。历史分位/z-score 统计属 P4，未在本阶段实施。

## 2. 来源门禁（阶段 0）

2026-08-10 实测财政部官网收益率曲线页面使用的公开接口：

- 单日全曲线 `czbQueryXy?zblx=xy&workTime=YYYY-MM-DD&qxmc=1`：JSON，111 个期限点，自 2006-03-01 起；未来日期、非工作日返回 `[]`。
- 单期限历史 `czbQueryYz?zblx=yz&gjqx=<期限>&startTime=&endTime=&locale=cn_ZH&qxmc=1`：JSON 序列；10 年全历史 5112 点无截断；未来结束日期只返回截至最新可用日；无效期限返回 `[]`。
- 年度 XLSX 文件入口（`queryXyFileList`）GET/POST 当前均 404 不可用。
- **偏离记录**：reports/68 §4.5 建议"历史回填优先走按年下载文件"。因年度文件入口当前不可用，改用官方页面实际使用的 `czbQueryYz` 单期限历史接口做有界回填（9 个关键期限共 9 次请求覆盖全历史，未来日期点由适配器防御性丢弃）。该接口与页面 y-z 坐标查询同源。
- 条款：网页页脚载明财政部版权所有、转载需注明来源；本项目为个人本地研究、不对外分发，符合 PRD §3.2/§3.3 边界。编制说明为 PDF 且无文本层，项目不新增 PDF 依赖，未逐字核对编制口径。

## 3. 实施范围

- `treasury_yield_curve` 独立表（曲线日期、期限、收益率、来源、抓取时间、原始哈希、置信度、批次）+ 索引，DuckDB 迁移 v9。
- `czb_mof` 独立适配器实例与限速（0.5s/请求）：单日全曲线与单期限历史两种模式；未来日期先验拒绝与响应防御丢弃；畸形响应为合法缺失（不熔断），网络异常进入 retry。
- `TreasuryCurveUpdater`：按期限历史回填（单期限事务原子替换）、日终 upsert、低频每日自动刷新（价格/财务优先后）、失败保留旧值并进入独立 retry/missing、`align` 对齐（≤价格日最近点、最大陈旧 5 个自然日）、只读状态报告。
- CLI `vd data treasury-curve`（回填/日终/检查）。
- 指标快照新增 10 列：`ttm_dividend_yield` 与 `div_yield_spread_0p25y/0p5y/1y/2y/3y/5y/7y/10y/30y`；TTM 口径为价格日前 12 个月已除权且已公告现金分红合计 / 收盘价；曲线陈旧超限或缺失时对应利差为 `null`；快照计算同时写 `source_audit` 溯源。
- 详情 API `GET /api/stock/{code}/treasury-comparison`：按价格日序列返回 TTM 股息率、对齐国债收益率、利差、曲线日、日期差与缺失原因，附曲线侧溯源。
- 前端股东回报章节新增国债比较卡：默认 10 年期利差历史，可切换利差/双线视图与 9 个关键期限；只做展示，不提供比值、提示或结论。
- 筛选：10 个新列进入快照白名单、排名指标、DSL 元数据与中文名称；导出溯源对利差列附加期限、曲线日与日期差（PRD §12.5）。
