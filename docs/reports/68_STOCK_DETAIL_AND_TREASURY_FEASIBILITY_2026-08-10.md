## 3. 历史总股本硬门槛

1. CNINFO `p_stock2215` 是主链：变动记录和半年/年报期末总股本锚点共同构成历史骨架。
2. 东财 F10 `RPT_F10_EH_EQUITY` 只作交叉校验；不得单独决定历史总股本，因为已实测存在错误中间事件。
3. 仅当 CNINFO 相邻锚点一致且中间无冲突事件，或来源明确持续有效时，才可将股本延续到中间交易日。
4. 双源冲突超过容差、锚点不一致或无可验证股本的日期必须 `missing`；禁止当前总股本、插值或默认值回填。
5. PE/PB 任一统计窗口内，历史总股本必须连续可验证覆盖至少 90% 的有行情交易日；否则该窗口统计不可用。
6. 上线前抽样至少20只含增发、送转、回购、期权行权、可转债转股和 A+H 情况的股票，与官方公告核验；默认十年窗口以此为放行条件。

## 4. 国债曲线硬门槛

1. 正式计算源仅为财政部-中国国债收益率曲线；不使用中债或其他源自动替换。
2. 每个点保存曲线日期、期限、收益率、来源、发布时间或抓取时间、原始响应哈希和置信度。
3. 对股票价格日 D，只取不晚于 D 的最近曲线点，最多陈旧5个自然日；实现必须拒绝未来日期。
4. 曲线任务为低频独立域，失败保留旧值并进入独立 retry/missing；不得进入 `stock_meta`、价格表、快照、基础池或 readiness。
5. 历史回填优先走按年下载文件；逐日接口仅用于日终增量与有界补洞。必须先在隔离 profile 验证年度文件字段与解析稳定性。

## 5. 数据和统计语义

- PE/PB：使用“最新重述回看”，即历史日对应报告期的当前最终财务值加历史有效总股本；必须标记“非当时可见，不用于回测”。
- TTM股息率：仅统计历史日之前已除权的过去12个月实际现金分红；分红占位日期或公告日期缺失需先通过既有数据质量门禁核验。
- 利差：TTM已实施现金股息率减所选期限国债收益率；首期默认10年期，不提供比值。
- 历史统计：只对 PE、PB、TTM股息率和国债利差计算。窗口为1/3/5/10年和全部，默认10年；门槛为120/360/600/1200/1200个有效日。经验视图为P10/P20/P50/P80/最大有效值；标准差视图为μ、μ±1σ、μ±2σ、z-score。PE≤0排除并标为不适用。
- 统计仅描述历史位置；不假设正态分布，不给出投资提示或自动结论。

## 6. 架构与安全门槛

- `company_profile`/`business_breakdown`、`treasury_yield_curve`、`share_capital_history` 和历史统计产出必须为独立表/域。
- 新 adapter 使用独立实例、限速、熔断、retry/missing 状态，防止业务或国债源失败传染股票价格源。
- 历史统计按单写者、staging 到原子发布、输入指纹和版本号建设；失败时保留上一发布版本。
- 历史统计型筛选只能 join 已发布统计域，不能将历史扫描或逐股曲线请求塞进当前筛选 SQL；仍须满足 5000股、10-20条件、5秒门禁。
- 所有正式写操作经 CLI 和既有路径隔离；探测、测试和回填先在 S1 profile 执行。

## 7. 视觉与体验门槛

详情页使用“财经终端骨架 + 本项目研究叙事”：高密度数值排版、研究型K线工具栏、清晰表格、粘性章节目录和可靠的空/错/陈旧状态；不复制东方财富或同花顺的皮肤、交易盘口、资金流、资讯流或自动提示。

实现前完成设计稿与图表交互定义；实现后对详情相关组件执行最新 Web 设计、可访问性和键盘操作审查。不得用临时 CSS 占位后再进行二次美化。
