# 东鹏饮料（605499.SH / 09980.HK）八位大师视角：买入点与买入方法

> **方法**：与 `reports/169–180` 同一套 —— 8 位大师各由独立 Agent 代入、各自跑 SQL；**第 9 个 Agent 做核验 + 双锚 + 反方**。

## 2. 核心："双杀"的前提不成立

| 项 | 变化 | 结论 |
|---|---:|---|
| **估值腿（PE）** | 从 95.9x（2021）杀到 **16.96x（−82%）** | **已杀** |
| **盈利腿（TTM 归母）** | **+9.56%**（仍在增长） | **未杀** |
| 结论 | — | **这是"单杀"，不是"双杀"** |

**所以现在定价的不是"已经便宜"，而是"E 腿会不会被杀"。**

**市场正好按 TTM × 17.0 定价**：47.99 × 17 = **111.1 元 ≈ 现价 110.89**（误差 0.2%）。
**反推隐含增长**：要在 110.89 赚 10%/年（E=45 亿、退出 15x），需要 **g = 6.6%** 永续增长——**而最新三个季度营收同比是 +21.5% → +11.3% → +0.75%**。

**FCF 锚交叉验证**：39.05 ÷ 6% + 净现金 = **107.8 元**；÷ 7% = **95.1 元**。
→ **现价对应 6.6% 永续增长；FCF 锚在 6–7% 要求回报下给 95–108 元。两侧都指向"合理"，不是"便宜"。**

## 5. 买入方法

### 5.1 三档 + 双确认（本票要求比前几家更严）

| 触发路径 | 条件 | 动作 |
|---|---|---|
| **价格触发**（主） | 触及 S1–S3 | 执行该档，同一档只打一次，两档间隔 ≥ 一个完整财报季 |
| **经营确认**（可提前一档） | ① **单季扣非同比 ≥0 连续两季**（现 Q3 −1.26%）；② **能量饮料本体同比 ≥+8%**（现 2026H1 +6.88%）；③ 单季毛利率 ≥45%（现 45.66% ✓）；④ 合同负债同比 ≥0（现 +42.9% ✓） | 可在高一档价位执行下一档的 1/2 |
| **禁止** | 单季毛利率 <43% 或销售费用率 >20% | 冻结（价格战确认） |

- **首笔 2%，上限 6%**（8 人给 5–10%，中位 8%；本报告收紧到 6%，理由：**71.82% 单品类 + 99.76% 内销 + 仅 5.5 年历史 + E 腿未证伪**）。
- **不设定投**：增长正在减速，按时间摊平等于在下行期持续买入。

| 7 | 能量饮料市占率连续两年下滑〔**需外部数据**〕 | 库内无 |

### 5.3 退出条件

1. **论点失效**：能量饮料收入连续两年负增长，且电解质+茶合计占比未从 21.94% 升过 30% → **清仓**（第二曲线没接上）。
2. **双杀确认**：单季营收同比连续两季为负 **且** 毛利率跌破 43% → 清仓（这时才是真的双杀）。
3. **估值退出**：PE ≥24x（≈163 元）或股息率 <2.5%（≈220 元）而增速仍个位数 → 减半；PE ≥30x → 清仓。
4. **资本配置退出**：payout 从 84.1% 掉到 <40% 且 capex/营收 >15%（开始乱投）→ 减半。
5. **治理退出**：大股东减持 >2% 或关联交易/资金占用 → 清仓。
