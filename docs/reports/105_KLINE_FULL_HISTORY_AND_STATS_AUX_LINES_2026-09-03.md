# K线全历史展示与历史统计辅助线自动回退修复

## 背景

1. 个股 K 线此前按固定 `days`（250/500/1000）取最近 N 根，不符合同花顺类软件
   “载入全部历史 + 滚轮缩放/拖动平移”的查看习惯。
2. 中国移动（600941）等 2022 年后上市股票，历史研究统计默认选择 10 年窗口，
   但因样本不足 1200 个交易日，10 年窗口统计整体为 `insufficient_samples`，
   分位线与均值线全部为 null，图表看起来没有辅助线。

## 修复

1. **K 线全历史**：
   - 后端 `GET /api/stock/{code}/kline` 的 `days` 改为可选；缺省返回全部可得
     K 线，显式传 `days` 仍按最近 N 根返回（兼容既有调用与回归测试）。
   - 周/月 K 同样在缺省 `days` 时对全部日线聚合，不再按时间窗口截断。
   - 前端移除固定范围下拉，改为 `klinecharts` 滚轮缩放 + 拖动平移；
     偏好持久化从 period/adjust/range 简化为 period/adjust。
2. **历史统计辅助线自动回退**：
   - 数据加载后若当前窗口统计不可用，按 10→5→3→1→全部 的优先级自动切换到
     最长可用窗口，并显示“已自动切换到 N 年窗口”的提示。
   - 中国移动默认会从 10 年自动切到 5 年，P10/P20/P50/P80/最大 与 μ±σ
     辅助线恢复显示。

## 验证

- 前端 lint / 69 Node + 57 Vitest / 生产构建全通过。
- 后端 Ruff 通过。
- 实测 600941 全量日 K：1,130 根（2022-01-05 → 2026-09-02）；
  600519 全量日 K：6,070 根（2001-08-27 → 2026-09-02）；
  显式 `days=250` 仍返回 250 根。
- 历史研究统计 API 数据核验：600941 的 1/3/5 年窗口有完整统计，10 年/全部
  为 `insufficient_samples`；前端回退后默认展示 5 年辅助线。
- 完整 S1 回归未跑（服务在线门禁拒绝），待停窗补跑。
