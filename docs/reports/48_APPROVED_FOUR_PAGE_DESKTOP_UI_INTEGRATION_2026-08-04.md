# 已确认四页桌面界面正式接入报告（2026-08-04）

## 1. 先样稿、后正式接入

本次界面变更严格按用户确认的流程执行：先在隔离路由
`/design-preview` 制作并迭代筛选、自选列表、个股详情（搜索与详情状态）和数据状态四页静态样稿；用户确认全部样稿后，才接入正式路径。

## 2. 正式接入范围

- 共享桌面壳层：浅色侧栏展示 V1 四模块（筛选、自选列表、个股详情、数据状态）。
- 筛选：保留草稿恢复、规则版本化、基础池、条件、排序、严格可信、服务端运行、保存、CSV 导出及加入自选的既有契约；采用已确认的工作区布局和中文优先指标名称。
- 自选：按默认手动组及各筛选规则名分组；从筛选结果加入自选时使用规则名作为组名，保留手动添加、移除、列配置与可信度遮蔽。
- 个股详情：模块内先进入居中的股票代码/名称模糊搜索状态，选中后进入现有详情；详情保留返回搜索入口、K 线、指标、趋势、溯源和 PDF 功能。
- 数据状态：采用已确认的桌面标题和就绪状态层级，保持只读与 CLI 维护边界。
