## 1. 保留的 10 条（完整口径）

### 27. ROCE 持久性（已实现 ⭐ 旗舰）

- **出处（更正）**：**普拉克·普拉萨德《我从达尔文那里学到的投资知识》第 2 章**。
  `app/core/indicators/roce.py` 文件头第一行即此出处，实现也按此口径。
  - 同源表述（不早于 2023 年的书）：Terry Smith（Fundsmith）、François Rochon（Giverny）、
    Joel Greenblatt 都强调「ROCE 要长期稳定在高位」，但**没有任何一本书给出
    「10 年中位 + 最低值 + 变异系数」这个三件套**——三件套是我们在 `reports/131`
    里把共同思想操作化的结果。`reports/131` §2 把它署给 Terry Smith + Rochon
    属**代理归属**，应改为上面这条。
- **公式**：
  ```
  ROCE_t   = EBIT_t ÷ 平均已动用资本_t
  EBIT     = 利润总额 + 财务费用          （缺前者时回退）
  已动用资本 = 总资产 − 流动负债          （≡ 净营运资本 + 全部长期资产）
  持久性三件套（最近 10 个有效年报）：
    roce_10y_median = MEDIAN(ROCE)
    roce_10y_min    = MIN(ROCE)          地板：十年里最差的一年赚多少
    roce_10y_cv     = STDDEV_SAMP(ROCE) / MEDIAN(ROCE)
  ```
- **窗口纪律（用户裁定，不可放宽）**：N 年中位必须由**恰好 N 个**有效年报算出，
  不足 N 年时该窗口为 NULL。5 / 10 / 20 年三档可选，界面默认展示 10 年。
- **字段**：`roce_history`（逐年）→ `indicator_snapshot.roce_10y_median / _min / _cv / _years`
- **阈值**：`roce_eligible` = 非金融 + 市值 ≥ 100 亿 + 有效年数 ≥ 5
- **⚠ 已知缺口（必须补）**：现行可筛条件**只看中位数**，不检查最近一年是否恶化。
  实测反例：**万科 A（000002）ROCE 十年中位 > 10% 仍被筛入**，原因是
  ① 十年中位数天然滞后（2016–2021 好、2022 后坏，坏年份不足 5 年）；
  ② 地产结算滞后（当期亏损要等结算才进利润表）；③ 门槛不含「最近一年」。
  **补丁**：加硬门槛 `roce_latest > 0`（或 ≥ 8%），并允许叠加 `roce_10y_min`。
- **陷阱**：金融股不适用（无流动/非流动划分，分母失真）；已按行业剔除，不参与筛选。

### 28. 增量资本回报率（5 年，双口径）

- **出处**：Chuck Akre + Tom Gayner（Markel）
- **公式**：
  ```
  NOPAT(t) = EBIT(t) × (1 − t_eff)
  EBIT     = 利润总额 + COALESCE(财务费用, 0)
  t_eff    = CLAMP(所得税费用 ÷ 利润总额, 0, 0.35)   （利润总额 ≤ 0 时取 25% 中性值）
  incr_roic_5y = [NOPAT(t) − NOPAT(t−5)] ÷ Δ已动用资本(5 年)
  ```
- **回答的问题**：过去攒下的资产回报高（存量 ROCE），不代表**今天新投的钱**还高。
- **字段**：`income_statement`（利润总额/财务费用/所得税）+ `balance_sheet`（总资产/流动负债）
- **与 27 的关系**：27 看存量效率，28 看增量效率，**不重复**。

### 12. 留存资本化率（经营口径增量资本回报）

- **出处**：Charlie Munger / Lou Simpson / Bill Ruane
- **公式**：
  ```
  RCR = [NOPAT(t) − NOPAT(t−N)] ÷ Σ留存收益
  留存收益 = 未分配利润 + 盈余公积（逐年累加）
  ```
- **回答的问题**：每留存 1 元，换来多少增量税后经营利润——复利引擎的实测转速。
- **与 11 的区别**：11 看**市场**有没有为留存的钱买单，12 只看**生意本身**转不转。

### 25. 现金转换率（自由现金流 ÷ 净利润）

- **出处**：Terry Smith（Fundsmith）
- **公式**：
  ```
  FCF = 经营活动现金流净额 − 资本支出
  CC_5y = Σ(近 5 个年报 FCF) ÷ Σ(同期净利润，只累计净利润 > 0 的年份)
  ```
- **回答的问题**：账面利润里有多少变成了真现金（利润含金量）。
- **判定线**：Fundsmith 口径要求长期 ≥ 1.0；0.8 以上算健康。
- **字段**：`cash_flow.cf_from_operating`、`cash_flow_activity.capex`、`income_statement.net_profit`

### 7. 股东盈余与股东盈余收益率

- **出处**：Warren Buffett（1986 年致股东信）
- **公式**：
  ```
  OE = 归母净利润 + 折旧摊销 + 非现金减值摊销 − 资本支出（作为维持性资本开支的上界代理）
  OE_Yield = OE ÷ 期末总市值
  ```
- **回答的问题**：股东真正能拿走的现金是多少，相当于市值几个百分点（可与国债直接比）。
- **陷阱**：资本支出里含扩张性投入时，OE 会被低估（这是保守方向，可接受，须在文档注明）。

### 1. 格雷厄姆数（合理价格上限）

- **出处**：Benjamin Graham
- **公式**：
  ```
  GrahamNumber = SQRT(22.5 × EPS × BVPS)       等价于 P/E × P/B ≤ 22.5
  判定：price ≤ GrahamNumber 才算便宜
  折价幅度 = GrahamNumber ÷ price − 1
  ```
- **口径要求**：EPS 取**年报归母**基本每股收益；BVPS 必须用 `bps_parent`（归母口径），
  不能用含少数股东权益的 `bps`，否则少数股东占比高的公司会被凭空算便宜。
- **陷阱**：EPS ≤ 0 或 BVPS ≤ 0 时必须置 NULL，**绝不能取绝对值开方**——
  否则巨亏公司反而得到巨大的 GrahamNumber，出现「越亏越便宜」的倒挂。

### 3. 盈利收益率与 10 年期国债利差

- **出处**：Benjamin Graham
- **公式**：
  ```
  E/P  = 归母净利润 ÷ 总市值 × 100%
  利差 = E/P − 10 年期国债到期收益率(%)
  格雷厄姆准则：E/P ≥ 2 × 债券收益率（本库无 AA/AAA 公司债，用国债代理 → approximate）
  ```
- **回答的问题**：同一笔钱，现在买股还是买债更划算。是唯一带宏观坐标的指标。
- **报告审查结论**：✅ 通过。

### 34. 个股周期调整市盈率（CAPE10）

- **出处**：Jean-Marie Eveillard（First Eagle）
- **公式**：
  ```
  CAPE10 = 总市值 ÷ (过去 10 个完整年报的归母净利润之和 ÷ 10)
  正常化盈利收益率 = 1 / CAPE10
  ```
- **回答的问题**：单年 PE 在周期顶显示「很便宜」、在周期底显示「很贵」，方向是反的；
  用十年平均利润才能区分「真便宜」与「周期高点的假便宜」。
- **字段**：只需 `income_statement.parent_net_profit` 十年序列 + 总市值（已有）。

### 11. 一美元测试

- **出处**：Warren Buffett
- **公式**：
  ```
  OneDollar = [市值(t) − 市值(t−N)] ÷ [留存收益(t) − 留存收益(t−N)]
  留存收益 = 未分配利润 + 盈余公积
  判定 ≥ 1.0 通过（即每留 1 元，市值至少涨 1 元）
  ```
- **回答的问题**：管理层把赚来的钱再投出去之后，公司整体有没有变值钱。
- **陷阱**：期间大额增发/回购/分红会扭曲市值口径，需在窗口内标注这些事件，或改用
  N = 5 年并剔除增发年份。

### 19. 神奇公式（资本回报率 × 盈利收益率 双排名）

- **出处**：Joel Greenblatt
- **公式**：
  ```
  ROC = EBIT ÷ (净营运资本 + 净固定资产) = EBIT ÷ (总资产 − 流动负债)
  EY  = EBIT ÷ EV，  EV = 股权市值 + 有息负债 + 少数股东权益 − 货币资金
  MagicRank = rank(ROC, 降序) + rank(EY, 降序)   —— 两个排名相加，越小越好
  ```
- **回答的问题**：好生意（高资本回报）和便宜（高盈利收益率）极少同时出现，
  用排名合成逼出两样都占的少数公司，同时抵消行业估值中枢差异。
- **与 27 的关系**：ROC 与 ROCE 同为资本效率口径，但神奇公式额外引入了**价格**这一半。

## 3. 评审中发现的必须修的问题

### 3.1 ROCE 没把「正在变坏」的公司挡掉（用户实测：万科 A）

**现象**：万科 A（000002）ROCE 十年中位 > 10%，仍在 `roce_eligible` 里。

**三个原因**：

1. **十年中位数天然滞后**：2016–2021 年万科是高周转好企业，坏年份不足 5 年，
   中位数仍停在好年份的水平；
2. **地产利润表滞后**：结算的是两三年前卖的房子，当期亏损要等结算才反映；
3. **可筛门槛太松**：现在只有「非金融 + 市值 ≥ 100 亿 + 有效年数 ≥ 5」，
   **完全不看最近一年和最低值**。

**补丁（待实施）**：`roce_eligible` 增加两个条件——

```
AND roce_latest > 0            -- 挡掉当期已经在亏损的公司
AND roce_10y_min >= 0.08       -- 地板门槛：十年里最差的一年也要 ≥ 8%
```

阈值可由用户在筛选面板调整（默认 0 / 8%），并保留「只看中位数」的宽松模式供对照。

### 3.2 归属更正

正确出处是**普拉克·普拉萨德《我从达尔文那里学到的投资知识》第 2 章**（我们代码里就是这么写的）。

「10 年中位 + 最低值 + 变异系数」三件套是**我们自己的操作化**，不是任何一本书的原文公式。
