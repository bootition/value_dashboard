## 2. 四个核心问题的答案

### 2.1 汇兑是噪音，但剔干净后只剩 +1.18%

| 口径 | 9M26 同比 |
|---|---:|
| 归母净利润（报表） | **−14.97%** |
| 利润总额（未剔除汇兑） | **−16.93%** |
| **利润总额（剔除汇兑）** | **+1.18%** |
| Q3 利润总额（未剔除 / 剔除） | −10.64% / **−5.26%** |
| 营收 | +2.47% |
| 毛利率 | +1.2pp（9M）；Q3 38.04% 同比 +0.14pp、**环比 −2.12pp** |

**结论：不是经营恶化，但也只能叫"低速平台期"。**
- **"没恶化"的硬证据是毛利率**：在营收只有 +2.47% 时，9M 毛利率 38.6%（+1.2pp）——**失去定价权的公司毛利率先塌，福耀没有**，说明逆风让在费用端（研发 +16%、安徽爬坡折旧、美国火情、海运费）而非价格端。
- **"不是稳健成长"的硬证据是增速**：营收 +2.47% vs 2018–2025 的 CAGR 12.4%，是断崖式减速。

### 2.2 PB 66.9% 分位 vs PE 19.7% 分位：不矛盾，是恒等式

**`PB 3.885 = PE 17.63 × ROE 22.03%`**

| 同一 PB 3.885 在不同 ROE 下 | 隐含 PE |
|---|---:|
| 2019 年 ROE 13.73% | **28.3x**（贵得离谱） |
| 2025 年 ROE 20.34% | 19.1x |
| 期末 ROE 22.03% | **17.6x** |

→ **PB 的高分位不是"贵"，是"市场已经把 ROE 从 14% 抬到 22% 这件事定价进去了"。**
→ **PE 的低分位不是"便宜"，是分母被汇兑压低（同时价格也跌了）。两个分位各自失真。**
→ **真锚 = 正常化盈利 + ROCE 可持续性**：2025 ROCE **23.02%**（2019 年 14.09%），且 **CE 从 2024 年 452.7 降到 2025 年 445.0，EBIT 从 83.4 升到 103.3——用更少的资本赚更多的钱**，这是最硬的质量证据。
→ **但 ROE 22% 是历史峰值**（净利率 20.34% 也是历史最高，含 3–4pp 周期）。若 ROE 回落到 18%，同样的 PB 3.885 会让 PE 跳到 21.6x。**所以买点必须留出 ROE 均值回归的余地。**

### 2.3 卖方预期 82.5 到 97.3 差 18%：谁的假设最可能对

**Q4 反推算术**（2025Q4 实际归母 **22.47 亿**，9M26 已实现 **60.06 亿**）：

| 全年目标 | 需要的 Q4 归母 | Q4 同比 | 判断 |
|---|---:|---:|---|
| 82.53 | 22.47 | **0%** | **基线**（Q4 仍有汇兑损失） |
| **87.74（华龙）** | 27.68 | **+23%** | **乐观上沿**（需"Q4 无汇兑损失 + 美国复产 + 安徽爬坡减亏"三件事同时成立） |
| 88.7（西南） | 28.64 | +27.5% | 偏乐观 |
| **90.6（库内一致预期）** | 30.54 | **+36%** | **偏高，隐含 3–5 亿汇兑净收益 —— 把"中性汇率"偷换成"有利汇率"** |
| **97.3（华安）** | 37.24 | **+66%** | **几乎不可能**（需人民币大幅反转） |

→ **基准 FY26 = 85–88 亿（−9% 到 −6%）**，对应现价 A **16.5–17.1x**。
→ **一致预期还有 5–6% 下修空间**——下修是买点，但要等它发生。
→ **额外发现（斯利普）**：卖方 18% 的分歧**基本不是经营分歧，是汇率假设分歧**。9M26 剔除汇兑后归母已约 68.8 亿，加 Q4 干净的 25–26 亿就是约 **94 亿**——华安其实是"全年零汇兑损失"假设，不是激进经营预测。**市场在为一张汇兑损益表吵架。**

### 2.4 A/H：买 H，但折价不是安全边际

| | A 股 | H 股 |
|---|---:|---:|
| 价格 | **55.78 元** | 54.25 HKD × 0.856 = **46.44 元** |
| **A/H 溢价** | — | **20.12%**（按 11-16 A 56.86 是 22.44%） |
| **H 对 A 折价** | — | **16.75%** |
| PE / PB | 17.63 / 3.885 | **14.69 / 3.23** |
| **股息率（毛）** | 3.94% | **4.74%** |
| **股息率（内地个人税后）** | **3.94%**（持股 >1 年免税） | **3.79%**（港股通 20% 红利税） |

**三个必须说清的点**：
1. **H 的税后股息反而低于 A**（3.79% vs 3.94%）。**H 的全部优势就是那 16.75% 的入场折扣本身。**
2. **A/H 折价不是安全边际**——安全边际只能来自"价格 vs 内在价值"，不能来自"价格 vs 另一个价格"。A 贵 20%、H 便宜 16.75%，只是"少贵一点"。且折价有制度成因（资本管制、流动性、指数、汇率），**可长期不收敛**，而回报并不需要它收敛。
3. **库内 H 股息率 2.58% 是错的**——它只用了最近一次分红 1.20，真实应为 2.20 ÷ 46.44 = **4.74%**（KB §27 `I-DPSATTRIB` 的老毛病复现）。

**另外必须纠正两位大师的口径错误（核验官抓的）**：
- **费雪把"22.44% 的 A/H 溢价"误写成"H 折价 22.44%"**（真实 H 折价 18.33% @11-16 / 16.75% @今日）
- **斯利普写"观察等待"却让 H 立即开 1/3**——标签与动作不符；其 H 触发价用"A ÷ 0.856"算绝对人民币等值（A 48 元 → 56.07 HKD），这隐含"维持当前 A/H 溢价"，**与"买 H 因为便宜"自相矛盾**。若按今日溢价，A 48 元对应的 H 只有约 46.7 HKD。

## 6. 单车价值量叙事：方向真，幅度是话术

| 检验角度 | 结论 |
|---|---|
| **总量校验** | 2025 营收 458 亿 ÷ 全球约 9000 万辆 × 34% 份额服务约 3000 万辆 → **单车配套约 1500 元，本来就不是 1000 元** |
| **做到 2500 元均值需要** | 十年 content CAGR **5.2%**，且天幕渗透率 20%→60%、调光 3%→20%、HUD 15%→45%，**且年降不能吃掉 mix** |
| **+8.03pp 值多少 ASP** | ASP uplift ≈ 8.03% ×（高附加值单价倍数 − 1）：倍数 1.5 → **+4.0%**；2.0 → +8.0%；3.0 → +16.1%。但**还需扣年降** |
| **净 ASP 现实数字** | mix 3–5% − 年降 3–5% ≈ **0–2%** |
| **裁决** | **值 2–3 个点的 ASP，不值 10 个点。给 10–15% 的期权价值，不放进基准估值。** |

**需要验证而现在都没有的三样**：① 单车 ASP 与配套套数的官方桥接（而非收入占比）；② 高附加值产品的绝对收入与单价倍数；③ 年降幅度披露。

## 8. 买入方法与退出

### 8.1 方法

1. **A 股只等不追**：48 / 43.5 / 39.5 三档预设限价，三档之间**不因下跌本身加仓**，只在"跌到价 + 15 要点未破"两条件同时满足时成交。
2. **H 股是为"折价"而非"故事"**：H 54.25 只在**实时报价、汇率、税负、流动性**四项复核后作第一档有条件首仓（最多 25% 计划仓位）。**不把 A/H 折价收敛写进任何收益假设。**
3. **总仓位上限 9%**（3% + 3% + 3%，按 25/30/45 分配）。
4. **不设"财报后追买"**：本轮已证明财报是噪音源（汇兑）。

### 8.2 停止买入的硬条件

| # | 条件 | 当前 |
|---|---|---|
| 1 | 剔除汇兑后连续两季利润同比 −10% 以上，且毛利率跌破 35% | 剔除后 +1.18% / 38.6% |
| 2 | **高附加值产品收入占比连续两年不再提升** | +8.03pp |
| 3 | 营收连续两季跑输行业 3pp 以上 | Q3 跑赢约 5pp |
| 4 | ROCE 跌破 15% | **23.02%** |
| 5 | 资本开支连续两年 > CFO 且增量 ROCE <12% | Q3 capex 15.9 / CFO 37.1 |
| 6 | 分红下调或取消 | DPS 2.20（TTM） |
| 7 | 美欧对中国汽玻加征关税或强制本地化，海外毛利率结构性下台阶 ≥3pp | 待观察 |

### 8.3 退出条件

1. **护城河退出**：毛利率连续 4 季同比下滑 ≥1.5pp（scale economies 开始被让渡给主机厂，这是唯一先行指标）。
2. **份额退出**：营收连续 2 年跑输全球轻型车产量增速。
3. **价值毁灭退出**：增量 ROCE 跌破 10%（安徽/合肥/福清的 capex 从增值变贬值）。
4. **股东回报退出**：DPS 下调或分红率跌破 40%。
5. **估值退出**：PB >5.0 而 ROE 未突破 25% → 先减仓不等基本面；A 股正常化 PE >24x 且盈利未上修 → 减半。
