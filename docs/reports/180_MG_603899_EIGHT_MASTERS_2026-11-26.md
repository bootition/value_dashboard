## 2. 核心：双低分位为什么不是两个信号

**恒等式拆解**：
```
PB(2.361) = PB中位(7.50) × [ROE 21.4% → 14.6% 的变化，即 0.6833] × [PE 35.1 → 16.17 的变化，即 0.4607]
          = 7.50 × 0.6833 × 0.4607 = 2.361  ✓
```
→ **PB 的 4.2% 分位 100% 可以由「ROE 掉了 32%」与「PE 掉了 54%」解释**。它不是一个独立的安全边际信号，而是**同一个"生意变差"事实的第二种写法**。

**现价的本质（审计最锋利的一段）**：
| 口径 | 收益率 |
|---|---:|
| 剔现金盈利收益率（8.5% 是市场常引的那个） | **8.5%** |
| 但股东**实际拿到的现金回报**（股息 4.31% + 回购 1.65%） | **5.96%** |
| 差额 | **2.5pp** |

差额从哪来？**公司留了 30% 利润（payout 69.7%），而增量 ROCE 是 −4.8%。**

**所以"零增长合理价 23.20"是有条件的**：
- **100% 分红假设下**：13.14 ÷ 5.5% ≈ 239 亿 ≈ **23.7 元** ✓ 与现价吻合
- **70% payout 假设下**：留存 30% 按 −4.8% 增量回报再投 → 合理价 **16.5 – 18.2 元**（现价高 **27%–41%**）

**一句话**：**现价 = 假设公司把所有利润都分掉的价格。而它没有。**

## 6. 买入方法

### 6.1 三档 + 经营双确认

| 触发路径 | 条件 | 动作 |
|---|---|---|
| **价格触发**（主） | 触及 S1–S3 | 执行该档，同一档只打一次，两档间隔 ≥ 一个完整财报季 |
| **经营确认**（可提前一档） | ① **毛利率 ≥19% 连续两季**；② **扣非 TTM 转正且加速**；③ CFO/净利 ≥1.0；④ 应收增速 ≤营收增速+5pp | 可在高一档价位执行下一档的 1/2 |
| **禁止** | 毛利率连续两季 <17.5% | 冻结（陷阱线） |

- **首笔 2%，上限 8%**（8 人给 4–8%）。
- **不设定投**：这是一门"利润率还在下行"的生意，按时间摊平等于在毛利率下行期持续买入。

### 6.2 停止买入的硬条件

| # | 条件 | 当前 |
|---|---|---|
| 1 | **毛利率连续两季 <17.5%** | 18.32%（TTM）/ 19.51%（9M26） |
| 2 | **扣非 TTM <−5% 连续两季** | +0.52% |
| 3 | 应收增速超营收增速 10pp 以上（渠道压货） | 待查 |
| 4 | **DPS 下调**（0.50→0.25 的历史证明它有这个能力） | 1.00 |
| 5 | 净现金跌到 <30 亿（27.5% 市值 → 14%） | 58.35 亿 |
| 6 | 出现大额跨界并购或大股东减持 | 库内无 |
| 7 | **科力普占比 >65% 且毛利率 <17%** | 57.69% / 18.32% |

### 6.3 退出条件

1. **估值退出**：PE ≥25x（≈36 元）或 PB ≥3.5 减半；PE ≥30x 清仓。
2. **分红纪律退出**：DPS 下调（历史已发生过两次）→ 清仓。
3. **生意退化退出**：毛利率连续两季 <17.5%，或扣非连续两季 <−5% → 清仓。
4. **资本配置退出**：net cash 超过 60 亿却 payout <60%、或出现 >10 亿的非同业并购 → 减半。
5. **渠道退出**：应收增速连续两年超营收 10pp（渠道压货）→ 减半。
