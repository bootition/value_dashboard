>
> | 标签 | 现价 | 什么能触发买入 | 是否给买点 |

> | 买入 / 分批买入 | 可建仓 | — | 给 |

## 2. 四个核心问题的答案

### 2.1 PE 19.31 / PB 2.528 是真贵，不是"资源股该换尺子"

| 分位窗口 | PE 中位 | **当前 19.31** | PB 中位 | **当前 2.528** |
|---|---:|---:|---:|---:|
| 3 年 | 14.8 | **97.3%** | 1.92 | **100.0%** |
| 5 年 | 13.2 | **98.4%** | 1.76 | **100.0%** |
| **10 年** | **9.9** | **97.5%** | **1.42** | **100.0%** |

**为什么"换尺子"救不了它**（马克斯的三把尺子，我复算全部成立）：

1. **峰值口径**：按当前股本折算 2022 年峰值 EPS **3.21 元**，51.82 元仍是 **16.1 倍**——**比 10 年中位 9.9 倍贵六成**。所以"资源股该看峰值利润"也救不了。
2. **反推口径**：现价隐含盈利收益率 **5.18%**；要求 8% 合理总回报，倒推永续增长率是 **+2.8%**，而**过去三年归母年化 −8.8%** —— **市场用负增长的三年定了永续正增长的价**。
3. **严格 EV 口径（本次复算最狠的一个）**：神华是**净负债 296.8 亿**（不是净现金），且**少数股东权益 969.2 亿**——严格 EV = 11,239 + 296.8 + **969.2 = 12,505 亿**：
   - **EV / TTM 归母 582.0 = 21.49x**
   - **EV / TTM 扣非 526.9 = 23.73x**

**7 位大师给出的 IV 中位中枢约 33–35 元，现价高 48%–57%。**

### 2.2 煤电一体化是内部对冲，而且 2026Q3 是净负贡献

**Q3 精确拆解（我复算）**：

| | 毛利（亿） | 同比变化（亿） |
|---|---:|---:|
| 煤炭 | 233.71 | **+31.09** |
| 发电 | 32.84 | **−36.05** |
| **两项合计** | — | **−4.96** |

→ **一体化没有让它多赚，而是让它少赚约 5 个亿，同时把利润表的波动磨平。**

**零和的原因在于两条价格通道都被堵死**：
- **向上被长协封住**：79.29% 自产煤走长协（且**已从 H1 的 84.69% 下滑**），煤价涨它涨不动
- **向下被管制电价封住**：Q3 发电成本 **+20.05%** 而电价只 **+0.5%**，毛利率被压到 **10.98%（−12.73pp）**

→ **煤价上行时煤炭端被长协削一刀、发电端按市场煤全额计亏，净效果为负；下行时反过来也补不满。**

**真正的护城河不在煤电对冲，在运输**：铁路+港口+航运 Q3 毛利 **52.9 亿**，是收费权性质、不受煤价影响的现金流；加上**357.7 亿吨储量**与坑口电厂成本优势。

**一句话：一体化平滑的是波动，不是增长。** 2022 年 696.5 亿 → 2025 年 528.5 亿 → TTM 582.0 亿，**浅 V 至今没回峰值**。

### 2.3 资产注入：绝对口径毁值，每股口径待验

```
增量 ROCE = (797.8 − 833.1) / (7,327.6 − 5,629.1) = −35.3 / 1,698.5 = −2.08%
```

**按 8% 资本成本，这 1,698.5 亿增量资本应产生约 136 亿 EBIT，实际是 −35 亿，缺口约 171 亿。**

**但要公平（三位大师都提到了）**：
1. **这是第一年**：红沙泉二号刚投产、塔然高勒与新街一/二井 2026–2029 才出量、煤制气 2027 年底才试车，**首年 ROCE 低估稳态**
2. **存量仍在增值**：12.32% 对 6% 的资本成本，经济利润仍有 460 亿量级——**公司毁掉的是回报率，不是价值**
3. **最关键但数据缺失的变量是"用什么付的"**：**若以高倍数发行股份购买低倍数资产，绝对 ROCE 下降只是会计现象、每股价值反而增厚**。净负债仅 296.8 亿（占市值 2.6%），没有大额举债痕迹，倾向股份支付，但**必须年报确认**

**裁定：绝对口径毁值，每股口径待验。**

### 2.4 A/H：该只买 H，但理由不是股息

| | A 股 | H 股 |
|---|---:|---:|
| 价格 | **51.82 元**（11-16 是 50.00） | 43.24 HKD × 0.856 = **37.01 元** |
| **A/H 溢价** | — | **35.09%**（按今日 A 51.82 对同一 H 价，约 **40%**） |
| PE（2026E）/ PB | 18.4x / 2.528 | **13.2x / 1.81** |
| **股息率（毛）** | 3.88%（库内 4.02%） | **5.43%** |
| **股息率（税后）** | **4.02%**（持股 >1 年免税） | **4.34%** |

**我复算的一条关键数字**：**H 税后股息只比 A 多 32bp。要靠这 32bp 的股息差追平 35.09% 的折价，需要 110 年。**

→ **所以"H 股息高"是错的买入理由**——股息税一动理由就崩。
→ **H 真正值钱的是资本折价**：同样 2.01 元分红，H 花 37 元买、A 花 52 元买，**分红一样多、本金少三成**，而资本利得目前不征税。

**买不了 H 的 A 股投资者**：A 仍值得买，**但起步价要从 35 元下移到 30 元**——35% 溢价若长期存在（资本管制 + 境内缺资产，倾向长期存在），A 投资者就是在为"买不了港股"永久性多付 35%，唯一补偿是要更低的价格。

## 3. DPS −38% 是口径错位（本轮第三个纠正）

| 口径 | 值 |
|---|---|
| **支付日 TTM（我数据包口径）** | 0.98（2026-10-26）+ 1.03（2026-07-13）= **2.01** |
| **这个 3.24 是怎么来的** | 0.98（2025-11-10）+ 2.26（2025-07-07）= **3.24** —— 但 **2.26 是 FY2024 末期、0.98 是 FY2025 中期，跨了两个财年** |
| **按财年归属** | **FY2024 = 2.26 → FY2025 = 0.98 + 1.03 = 2.01 → 真实 −11.1%** |
| 派息率 | FY2024 约 **126%**（EPS 2.573）→ FY2025 约 **82.5%**（EPS 2.437） |

→ **主因是派息率从 126% 回归 82.5%（解释约 34 个点），EPS 下降只解释约 5 个点。** **不是煤价单独决定，也不是分红政策突然推翻。**

**双向结论**：
- **坏消息**：那个"7% 股息率"的叙事从来是假的，现在只剩 **A 3.88% / H 5.43%**
- **好消息**：**2.01 元站得住** —— 2026E EPS 2.81 × 65%–80% 派息 = 1.83–2.25 元，TTM 的 2.01 正落在中间，且高于公司「2025–2027 不低于 65%」的承诺线

→ **高股息逻辑没破产，只是从"7%"被修正到"3.9% / 5.4%"。3.88% 对 1.59% 国债只有 229bp 利差，对一家 13% ROE 的公司——太薄，构不成买入理由；但 30 元对应 6.70%、26 元对应 7.73%，那就是另一回事了。**

## 6. 买入方法与退出

### 6.1 方法

1. **只做左侧**：价格不到不动手，宁可错过不可买错。**"我不是在等下跌，是在等赔率。"**
2. **H 优先，但 A-only 要更严**：A-only 跳过 T1、从 30 元起建仓、总仓位打七折（上限 7%）。
3. **价格是必要不充分条件**：每档必须叠加"长协占比止跌 / 发电毛利同比转正 / 卖方停砍盈利"三项中至少两项。
4. **不加杠杆、不向下摊平超过 T3**，每档间隔 ≥10% 或 ≥ 一份财报。
5. **单票上限 10%**（2/4/4）——比前几家都高，但理由是**这家的下行有储量与资产底**，不是因为它便宜。

### 6.2 停止买入的硬条件

| # | 条件 | 当前 |
|---|---|---|
| 1 | **DPS < 1.80 元，或派息率跌破 65%** | 2.01 / 82.5% |
| 2 | **长协占自产煤跌破 70%** | 79.29%（H1 是 84.69%，**在下滑**） |
| 3 | **注入资产连续两年增量 ROCE < 8%** | 首年 −2.08% |
| 4 | **合并 ROCE 连续两年 < 10%** | 12.32% |
| 5 | **CFO < 600 亿 或 净负债/EBITDA > 2.0** | CFO 750.6 / 净负债 296.8 |
| 6 | 继续以不透明对价收购集团资产 | 6.18 亿煤制气 50%（关联交易） |

### 6.3 退出条件

1. **高股息逻辑破产**：DPS 连续两年 <1.5 元或派息率 <60%，且无重大资本开支解释 → 卖出。
2. **资本配置失败**：资产注入满产后增量 ROCE 仍 <8%，或继续高价收购低效资产 → 卖出。
3. **一体化由对冲变拖累**：发电毛利率连续两季 <5% → 下修正常化 EBIT。
4. **资源基础破坏**：商品煤产量连续两年下降 >5%，或储量/产能被政策、事故下修 → 卖出。
5. **估值退出**：回到 45 元以上而 2027E 盈利仍在下修 → 减仓。
6. **量价背离**：煤价上行而股价不再创新高 → 周期见顶最早信号，兑现。

### 9.3 根因（已用受控实验定位）

同一份文件、同一个 Agent 重跑，对 schema 做二分：

| 变体 | 结果 |
|---|---|
| 原 schema（含 `enum` + `buy_points` 嵌套对象数组） | **null ✗** |
