## 2. 四个核心问题的答案

### 2.1 PB 0.593 破净：是价值陷阱，不是安全边际

**8/8 全部写出了同一个恒等式**：

```
PB 0.593 = PE 17.75 × ROE 3.34%   （分毫吻合）
```

→ **0.593 不是"资产打四折"，是"资产回报率打三折"被市场正确翻译成价格。**

**三条支撑**：
1. **ROE 从 2018 年约 11% 崩到 3.34%**（归母从 145.4 亿降到 59.0 亿，**−59.4%**）
2. **戈登模型反推**：按 7.5%–8% 股权成本、2% 永续增长，**0.593 的 PB 已隐含可持续 ROE 约 5.0%–5.6%**，是当下 3.34% 的 1.6–1.7 倍——**市场已经预付了修复**。若 ROE 停在 3%–4%，合理 PB 只有 **0.22–0.42**
3. **1,646 亿归母权益的主体是钢轨、路基、隧道**——不能清算、不能转产、不能自主提价（运价受发改委管制）

**核验官最锋利的一句**：**"以 8% 要求回报、零增长，合理 PB 约 0.42，合理价约 3.48 元，和当前 4.94 元仍有 42% 的距离。"**

### 2.2 运量 +8% 而利润 −17%：七分被动接盘，三分战略

**边际算术（核验官算的，比任何定性判断都硬）**：
- H1 营收 372.8 → 396.0 亿（**+23.2 亿，+6.2%**）
- 两端物流辅助费 9.07 → 21.98 亿（**+12.91 亿**）
- **毛利额反而从 52.1 亿降到 51.2 亿（−0.9 亿）**
- → **增量毛利率约 −4%**

**剔除这 12.91 亿让利，毛利本该 +12 亿；实际倒贴 0.9 亿。**

→ **"多拉 2.5% 的货、多收 23 亿，毛利还少了近 1 亿"——这不是"先投入后收获"的曲线，是"用毛利买运量"的直线。**

**最凶的一条**：**2026Q3 毛利率 7.63%、9 月大秦线运量 −0.15% 年内首次转负——量增先熄火，费用留在了成本表里。**

**战略的四条判据、期限 2027 年中报（2027-08-31）**：
1. 两端物流辅助费占营收比重**见顶回落**
2. 运输分部毛利率回到 **12%** 以上并连续两季
3. 非煤总包毛利率**转正 ≥3%**
4. 运量增速与毛利率**同向**

→ **现在成立 0 条，第 4 条刚被 9 月运量转负打脸。** 届时仍无一成立，就判定为**结构性让利（永久降价）**，长期盈利能力假设一次性下修。

### 2.3 主业还赚钱，但比表面少得多——被市场按成长股定价

| 口径 | 归母（亿） | PE（市值 976 亿） | EV/净利（EV 837.8 亿） |
|---|---:|---:|---:|
| TTM 报告 | 55.0 | 17.75x | 15.23x |
| TTM 扣非 | 54.6 | 17.88x | 15.34x |
| **H1 年化的主业**（剔除朔黄） | **53.74** | **18.16x** | 15.59x |
| **TTM 口径主业**（55.0 − 朔黄年化 30.6） | **24.4** | **40x** | 34.3x |
| **Q3 推算主业**（15.69 − 朔黄单季约 7.7 = 约 8 亿，年化 32） | **约 32** | **30.5x** | — |

**核验官的关键提醒**：**"18.16 倍"是 H1×2 的乐观年化——等于假设下半年和上半年一样好。但 2025H2 归母只有 17.85 亿、2025Q4 亏 3.24 亿、2026Q3 已降到 15.69 亿。**

→ **主业的真实估值区间是 25–35 倍，只有在煤运量稳定、让利退出、Q4 不再亏损时，才配得上 12 倍。**

**更本质的一句话（芒格）**：**"这家公司正在变成「一个持有朔黄 41.16% 的封闭式基金 + 一条回报率不足的大秦线」。"**

### 2.4 DPS −56.6%：高股息逻辑已经破了

| 口径 | 值 |
|---|---|
| 按支付日 TTM DPS | **0.22177** → 股息率 **4.49%** |
| 2024 年合计（对比基准） | 0.12924 + 0.38193 = **0.51117** → 名义 **−56.6%** |
| **按财年归属** | FY2024 约 0.26924 → FY2025 约 0.22169，约 **−17.7%**（**但绝对分红从 92.6 亿降到 44.0 亿，−52%，这个是真的**） |
| **TTM 派息率** | 0.22177 / 0.2784 = **79.7%**（远高于 55% 承诺） |

**三条致命点**：
1. **"不低于 55%" 只覆盖 2023–2025 年，已到期**，2026 年起没有新承诺 —— **把到期承诺当永续债票息，是把希望当事实**
2. **派息率已 79.7%，分红是被利润逼下来的，不是主动留钱，派息率已无缓冲垫**
3. **经营现金流封顶**：2025 年 CFO 仅 **49.9 亿**，而 TTM 分红约 **43.8 亿** → **覆盖仅 1.14x，扣掉 capex 大概率不覆盖**

→ **若按 55% 派息率推可持续 DPS**：以 TTM EPS 0.2784 算 **0.153 元**、以 2026E 0.302 算 **0.166 元** → 要求 6%–7% 股息率对应 **2.19–2.77 元**。

→ **4.49% 对 1.59% 国债只有 290bp 利差，补偿不了"单季会亏（2025Q4 −3.24 亿）、TTM −17.41%、ROCE 4.28%"**。

## 3. 压力测试：8/8 都没做的那道题

**基准**：TTM 营收 788.2 亿，四季度加权毛利率约 7.08%，毛利约 55.8 亿，归母 55.0 亿。

**假设**：运量 −10%、价格不变、毛利率再降 2pp 到 5.08%

| 步骤 | 结果 |
|---|---|
| 营收 | 788.2 → **709.4 亿** |
| 毛利 | 55.8 → **36.0 亿（减少 19.8 亿）** |
| 税后减少（25% 所得税） | 14.8 亿 |
| 扣少数股东漏出（约 14%） | 归母减少约 12.7 亿 |
| **归母** | **55.0 → 约 42.3 亿** |
| 若考虑少数股东漏出为 0 | 约 40.2 亿 |
| **若两端物流费用刚性维持 43.96 亿（H1 年化）** | 额外压 2–3 亿 → **39–41 亿** |
| **若朔黄也降 10%** | 再减约 3 亿 → **36–38 亿** |

→ **结论：归母从 55 亿掉到 36–42 亿，对应 PE 23–27x。若按 40 亿算，当前 4.94 元是 24.4 倍。**

**这才是"运量 +8% 不能直接翻译成利润见底"的真正原因。**

## 7. 买入方法与退出

### 7.1 方法

1. **价格 + 基本面双闸门**，价格是必要条件不是充分条件（无例外）。
2. **现价 0 仓，不挂自动单**：3.15/2.80/2.50 只是研究坐标。
3. **每档至少隔一个完整财报季**，不因下跌自动加仓（**"下跌本身不是买入理由"**）。
4. **总仓上限 5%（1.0 / 1.5 / 2.5）** —— ROCE 4.28% 的生意不配更高。
5. **若 2026 年报 Q4 再次出现负毛利、DPS <0.18、或两端物流费继续高于营收增速，三档全部作废，重新估值。**

### 7.3 退出条件

1. **逻辑破坏（不等价格，直接认错）**：2027 年报综合毛利率仍 <9%、两端物流费占营收 >8%、且 CFO <60 亿。
2. **股息锚失效**：2026 年度 DPS <0.15 元，或派息率跌破 55%，或新三年规划取消下限。
3. **SOTP 下修**：朔黄投资收益同比 −20% 以上，或朔黄分红政策变化、浩吉分流实质冲击。
4. **运量趋势破坏**：大秦线年运量连续两年负增长，且非煤总包毛利仍为负。
5. **估值兑现**：PB 回到 0.75 以上或股息率跌破 3.5% → 分批减仓。
6. **利率反转**：10Y 国债回到 3% 以上，类债券估值支柱消失 → 减仓。

## 8. 与 `reports/175` 对账

| 要素 | 175（第一轮） | 本轮 | 裁决 |
|---|---|---|---|
| 判决 | **2 买 / 6 观察** | **0 买 / 6 观察 / 2 不买** | ⬇️ **买方阵营消失** |

| **运量 +8%** | **当作需求没问题的证据** | **是"用毛利买运量"，增量毛利率约 −4%** | **❌ 175 的第二个错误** |
| **让利引流** | 当作阶段性 | **2027 中报四条判据无一成立即判结构性** | ✅ 补上判据与期限 |
| **压力测试** | 无 | **煤运量 −10% → 归母 36–42 亿，PE 23–27x** | ✅ 补上 |
| **投资收益依赖** | 未量化 | **占 H1 归母 36.8%；TTM 口径主业 PE 约 40x** | ✅ 补上 |

**175 的两处结论性错误**：
1. **把 PB 0.593（全史 2.0% 分位）当作安全边际**——8/8 全部推翻。
2. **把「运量 +8%」当作「需求没问题」的证据**——真实是增量毛利率约 −4%，是拿毛利换来的运量。

**175 被本轮确认的一条**：「PE 17.75 是 10 年 95.9% 分位的周期顶部低 PE」—— 本轮进一步解释：**PE 与 PB 一高一低是同一件事的两面**（分子跌三成、分母跌七成，商自然创高分位）。
